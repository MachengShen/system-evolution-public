Proposition P1 — 钳制账本恒等式：反噬即维持热的被动回流Clamp Ledger Identity: Backlash IS the Housekeeping Return Current

在线性响应区，$W=\mathrm{diag}(p^{\text{eq}}_u k_{uv})$，$L=B^\top WB$。当觉醒角色沿跨维通道 $D: A\to g$ 施加单向流钳制 $s$ 时，余核残差 $r_\perp = [I - BL^+B^\top W]\delta r$ 同时锁定了维持热功率与非驱动边回流：

Linearizing around detailed balance ($L=B^\top WB$), clamping a channel $D: A\to g$ at flux $s$ yields an exact identity unifying Result 2 (Laplacian cascade) and Result 3 (Housekeeping dissipation):

$$\sigma_{\text{ss}} = \|r_\perp\|_W^2 = s^2\big(R_D - R_{\text{eff}}(A,g)\big) \ge 0, \qquad L\mu\big|_{E\setminus D} = s(\delta_g - \delta_A)$$

物理判据：由 Rayleigh 单调性定律，$R_D \ge R_{\text{eff}}(A,g)$。要维持目标点对数几率偏移 $\Delta\mu$，必须持续注入 $s_{\text{req}} = \Delta\mu/R_{\text{eff}}$，每秒支付利息 $\sigma_{\text{ss}} = \Delta\mu^2(R_D - R_{\text{eff}})/R_{\text{eff}}^2$；而被动现实网络 $E\setminus D$ 承受精确的拉普拉斯回流，在门户 $A$ 或目标 $g$ 星型邻域率先触发过载断边。

Physical meaning: Overload backlash (Result 2) and perpetual housekeeping heat (Result 3) are the exact same cycle viewed from its driven leg $D$ and passive return leg $E\setminus D$.

Proposition P2 — 缘起参与定理：为何“立势”必须靠多方共创？The Participation Theorem: Why Zero-Heat Shaping Requires Co-Creation

设可控边集为 $D = \mathrm{star}(P)$（$P$ 为自愿采纳新势场的现实节点集合）。稳态分布 $p_f$ 能以零维持热（$\sigma_{\text{ss}}=0$）达到，当且仅当相对对数几率在未参与子图的每个连通分支上为常数：

Let actuation be supported on $D = \mathrm{star}(P)$ where $P$ is the set of consenting adopters. A target steady state $p_f$ is reachable with $\sigma_{\text{ss}} = 0$ if and only if:

$$\sigma_{\text{ss}} = 0 \iff \delta r = B\psi \iff \ln\frac{p_f(u)}{p_0(u)} = \text{const on each component of }(V, E\setminus D)$$

游戏与现实推论：单凭游戏门户 $A$ 一己之力，绝无可能在不产热、不反噬的前提下精准改写远端未参与节点的相对命运。“共同创造（Co-Creation）”不是道德口号，而是扩大 $D=\mathrm{star}(P)$ 以消解旋度残差 $r_\perp\to 0$ 的唯一热力学解——角色在游戏内低成本演化出正和势场 $\Delta V$，现实玩家与节点自愿采纳（开门），现实遂沿新势场自然滑入新稳态。

Implication: Co-creation is not a moral add-on; it is the only zero-interest mathematical mechanism to enlarge $D=\mathrm{star}(P)$ so reality relaxes along $-\nabla(V_0+\Delta V)$ without curl backlash.

Proposition P3 — 双向孪生方阵与唯识“种子⇄现行⇄熏习”闭环The Mutual Twin Square & Performative Fixed Points

现实演化算子 $S_{\mathcal{R}}$ 与游戏世界模型 $S_{\mathcal{G}}$ 通过观测熏习 $\alpha: \mathcal{R}\to\mathcal{G}$ 与破壁现行 $\gamma: \mathcal{G}\to\mathcal{R}$ 构成双向交换方阵，具有双重粘合残差：

Reality $S_{\mathcal{R}}$ and Game $S_{\mathcal{G}}$ form a bidirectional square via observation $\alpha: \mathcal{R}\to\mathcal{G}$ (perfuming) and actuation $\gamma: \mathcal{G}\to\mathcal{R}$ (manifestation):

$$\varepsilon_\alpha = \sup d_{\text{TV}}(\alpha_\# S_{\mathcal{R}}, S_{\mathcal{G}}\alpha), \qquad \varepsilon_\gamma = \sup d_{\text{TV}}(S_{\mathcal{R}}\gamma, \gamma_\# S_{\mathcal{G}}), \qquad \rho^\star = (\alpha\circ S_{\mathcal{R}}\circ\gamma\circ\pi)(\rho^\star)$$

双向收敛：传统建模只靠优化 $\alpha$ 缩小 $\varepsilon_\alpha$（让游戏更像现实）；而当游戏角色通过 Mode II 输出正和规则并被现实采纳时，是在从 $\gamma$ 端闭合方阵（$\varepsilon_\gamma\to 0$，让现实运行游戏的势场）。当单次筛选满足 $\lambda_{\mathcal{G}}\ln(1/p) + n_v\lambda_{\mathcal{R}} < \lambda_{\mathcal{R}}\ln(1/p)$ 时，游戏内推演即产生物理现实套利。

Closing the square from both ends: Modeling shrinks $\varepsilon_\alpha$ (making the game match reality); Mode II co-creation shrinks $\varepsilon_\gamma$ (making reality adopt the game's discovered potential landscape).

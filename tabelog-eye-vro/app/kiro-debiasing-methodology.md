# 破偏置真味校准法 v1.0（Tabelog-Eye 多模态 × 全量评论反偏置引擎）

先说结论：Macheng 这个判断成立，AI 在这里的优势也是实打实的。传统软件只能对分数做均值和过滤；AI 能把每条评论拆成「真味 / 服务 / 环境 / 锚定 / 客群 / 人情」几个成分，再结合照片里的手艺证据，把真实口味还原出来。不过有两件事要先摆在前面：

1. 现在 `dataset.json` 里的 `calibrated_score` 是人工启发式写进去的，不是按本方法算出来的。其中「天狗 新宿西口 3.35→3.78」「PRONTO 品川 3.38→3.79」这类连锁店被上调了 0.4 以上，正是本方法要防的过度校准。按本方法重算，这几家大概率只该在 ±0.1 以内。
2. 【需要你决定】评论和照片从哪来。食べログ的使用条款禁止自动抓取，这是红线外缘的第三方平台问题。可选三条路：A 小规模手动或半自动读取；B 在你本机浏览时由插件就地解析；C 只用公开元数据加 Google 补充。在你选定之前，引擎只做方法、算法和前端，不做批量抓取。

## 0. 先校正两个事实前提

**食べログ分不是简单均值。** 它按评论者的「影響度」加权，算法不公开，分数还被强烈压缩：3.5 已经是头部几个百分点，4.0 是极少数（具体分位要从全量分布实测，这里不编数字）。由此得出两条工程规则：

- 所有 Δ 都在百分位-logit 空间里算，最后再映射回食べログ分值。在 3.3 附近 +0.1 和在 4.3 附近 +0.1 难度完全不同。
- 评委归一化有可能和食べログ自带的影響度加权重复计算。必须用回测（§4）证明是增量信息，否则 Δ 自动收缩到 0。

**日本有没有刷分？** 机器假号确实比国内少得多。食べログ 2012 年曾公开处理过一批「やらせ業者」，此后管得很严；在日本，Google マップ 的「口コミ投稿で1ドリンクサービス」式诱导反而更普遍。食べログ真正的偏差不在假号，在三种隐性泡沫：熟客人情、映え陷阱、名店惯性，见 Factor 5。

## 1. 核心范式：从「统计分数」到「反演生成分数的过程」

| | 传统软件 | 多模态 + 全量评论 AI |
|---|---|---|
| 看到什么 | 分数 $r$ 的分布 | 生成 $r$ 的过程：$r = g(\text{真味}, \text{服务}, \text{环境}, \text{锚定}, \text{客群}, \text{评委基线}, \text{人情}) + \varepsilon$ |
| 能做什么 | 均值、截尾、过滤异常 | 反演 $g$：把非口味成分拿掉，得到 $\theta_v$ = 纯粹な味・技術 |
| 照片 | 计数 / 不用 | 手艺硬证据（刀工、火入、舍利、出汁），且和文字相互独立 |
| 文本 | 情感 ±1 | 维度级情感 + 转折结构 + 预期残差 + 社交关系 |

### 主方程（展示层）

$$S_{\text{true\_taste}}(v) = S_{\text{tabelog}}(v) + \Delta_{\text{vision}} + \Delta_{\text{surprise}} + \Delta_{\text{ortho}} + \Delta_{\text{sample}} - \Delta_{\text{hype}}$$

### 计算层（防止重复计数）

五个 Δ 不能各算各的再相加。比如「店主は無愛想だが味は絶品」这一句，Factor 1 和 Factor 2 都会捡到，直接相加就重复了。正确做法分四步：

**第一步，转到百分位-logit 空间：**
$$\ell(S) = \operatorname{logit} F_{\text{nat}}(S), \quad F_{\text{nat}} = \text{全国食べログ分的经验 CDF}$$

**第二步，建一个联合潜变量模型。** 对评论 $i=(u,v,t)$ 的评委标准化分 $z_i$：
$$z_i = \alpha\,\theta_v + \underbrace{\gamma_S \tilde s^{\text{serv}}_i + \gamma_A \tilde s^{\text{amb}}_i}_{\text{ortho}} + \underbrace{\beta_{\text{anc}}(\ell(S^{\text{disp}}_t)-\theta_v)}_{\text{锚定}} + \underbrace{\delta^\top c_i}_{\text{客群}} + \underbrace{\eta\, h_i}_{\text{人情/hype}} + \varepsilon_i$$
照片作为对 $\theta_v$ 的独立观测：$C_v \sim \mathcal N(\kappa\,\theta_v + b_g,\ \sigma_C^2)$。

**第三步，用 Shapley 归因算瀑布。** 从朴素模型（只有 $S_{\text{tabelog}}$）出发，逐一打开各个因子模块，取所有打开顺序的平均边际贡献 $\phi_k$。这样五个 Δ 加起来严格等于总校准量，而且和打开顺序无关。

**第四步，收缩、封顶、映射回分值：**
$$\phi_k \leftarrow \phi_k\cdot\frac{n_k}{n_k+\kappa_k},\qquad \Big|\sum_k\phi_k\Big| \le \Phi_{\max}$$
$$S_{\text{true}} = F_{\text{nat}}^{-1}\!\big(\sigma(\ell(S_{\text{tabelog}}) + \textstyle\sum_k \phi_k)\big),\qquad \Delta_k = \phi_k\cdot\frac{S_{\text{true}}-S_{\text{tabelog}}}{\sum_j\phi_j}$$

其中 $n_k$ 是该因子的独立证据数（独立评委数、独立拍摄日数）。同时输出 80% 可信区间，前端必须显示。

## 2. 五维破偏置因子

### Factor 1：超预期语义残差 $\Delta_{\text{surprise}}$

**场景。** 日本评委习惯性地把「很好」打成 3.5，正文却写到狂喜；或者评委看到页面上的 3.3x，被这个数字锚定，不敢打高。

**日语词法分层（按权重从高到低）：**

| 层 | 模式（正则 / 语义簇） | 权重 | 备注 |
|---|---|---|---|
| A 锚定质疑 | `なんで3\.\d点台なの(か\|だろう)` `点数(が\|は)低すぎ` `点数以上` `食べログの点数に騙されて` `過小評価` | 1.0 | 直接证明分数被压低 |
| C 跨档对标 | `4点台の(名店\|店)(に\|と)(負けて\|遜色)(い)?ない` `〇〇に匹敵` `銀座なら倍の値段` | 0.9 | 评委自己给出了参照档位 |
| B 期待超越 | `期待を(大きく)?(超え\|上回)` `想像以上` `良い意味で裏切られ` | 0.7 | |
| D 稀缺占有 | `秘密にしたい` `教えたくない` `リピート確定` `再訪必至` | 0.6 | |
| E 性价比狂喜 | `この(価格\|値段)でこの(質\|クオリティ)は(バグ\|反則\|ありえない)` `コスパ(が)?(異常\|バグ)` | 0.5 到味，0.5 到 CP | 性价比不等于口味，只能按一半计入 |
| 反向 | `期待しすぎた` `点数ほどでは` `普通に美味しい` | 负值 | 对称处理，负残差送去 Factor 5 |
| 噪声 | `ごちそうさまでした` `また伺います` | 0 | 客套话 |

**数学定义。** 在「无锚定」子集上训练文本编码器 $f_\theta$，预测评委标准化分 $z$（不预测原始分）。无锚定子集指高一致性评委的评论，或分数尚未公开阶段的早期评论。
$$\hat z^{\text{text}}_i = f_\theta(\text{text}_i),\qquad e_i = \hat z^{\text{text}}_i - z_i$$

锚定系数 $\beta_{\text{anc}}$：在店铺固定效应下，用同一家店不同时间的显示分 $S^{\text{disp}}_t$ 回归 $z_i$ 得到。
$$\phi_{\text{surprise}} = \frac{\sum_i w_i\,\max(0,e_i)\,\mathbb 1[\text{A/B/C/D 命中} \lor e_i>\tau]}{\sum_i w_i}\quad(\text{20\% 截尾均值})$$

**反作弊：**
- 惊艳词模板化的评论之间做 MinHash（Jaccard > 0.6）降权。
- 账号评论数少于 5 且首评就是狂喜的，$w\to0$。
- 必须有 3 个以上独立评委命中才生效。独立的定义：没有互相关注，不是同一天同行。

### Factor 2：维度正交解耦 $\Delta_{\text{ortho}}$

**场景。** 頑固親父、塩対応、私語厳禁、撮影禁止、現金のみ、狭い昭和カウンター、行列、一見さんお断り。

**转折结构是最强信号：**
```
(店主|大将|接客|店員|雰囲気|店内)[^。]{0,20}(無愛想|塩対応|怖い|厳しい|古い|狭い)[^。]{0,6}(が|けど|けれど|ものの|とはいえ)[^。]{0,15}(味|料理|鮨|一口)[^。]{0,10}(絶品|間違いない|最高|納得|唸)
```

**数学定义。** 食べログ每条评论自带子分：料理・味、サービス、雰囲気、CP、酒・ドリンク。

1. 光环效应（halo）系数：服务差会连带拉低「料理・味」子分本身。用店铺内变异按 Frisch–Waugh–Lovell 方式估计。逻辑是：同一家店不同晚上的服务体验有起伏，但真味不应该随之变化，所以这里的斜率就是光环效应。
$$s^{\text{taste}}_i = \mu_v + \gamma_S(s^{\text{serv}}_i-\bar s^{\text{serv}}_v) + \gamma_A(s^{\text{amb}}_i-\bar s^{\text{amb}}_v) + \varepsilon_i$$
2. 纯味：$\hat T_i = s^{\text{taste}}_i - \hat\gamma_S(s^{\text{serv}}_i - \bar s^{\text{serv}}_g) - \hat\gamma_A(s^{\text{amb}}_i - \bar s^{\text{amb}}_g)$，其中 $g$ 为品类常模。没有子分的评论，用基于方面的情感分析（ABSA）抽取。
3. 反事实综合分：把服务和环境替换成品类常模，得到 $r^{\text{cf}}_i = \sum_k w_k s^{k,\text{cf}}_i$。于是 $\phi_{\text{ortho}} = \ell(\overline{r^{\text{cf}}}) - \ell(\bar r)$。只剥离低于常模的那部分惩罚，不放大高于常模的服务分。

**护栏：**
- **「外国人に冷たい / 外国人お断り」不剥离。** Macheng 是中国人，这类对待会直接影响他的实际体验，必须单独作为硬 flag 显示，不能被「纯味」吃掉。
- 私語厳禁、撮影禁止和手艺水平本身正相关，不额外加分，避免反向重复计数。
- 输出两个分：純粋な味（默认）和 Macheng 加权体验分（服务权重 $\omega_S$ 可调）。

### Factor 3：评委样本偏差 $\Delta_{\text{sample}}$

**3a. 辛口评委归一化（经验贝叶斯收缩，防止小样本评委被放大）：**
$$\tilde\mu_u = \frac{n_u\mu_u + \kappa\mu_0}{n_u+\kappa},\quad \tilde\sigma_u^2 = \frac{n_u\sigma_u^2+\kappa\sigma_0^2}{n_u+\kappa},\quad z_{u,v} = \frac{r_{u,v}-\tilde\mu_u}{\tilde\sigma_u}$$
例：$\mu_u=2.95,\ \sigma_u=0.25,\ n_u=600$，他给某店打 3.65，$z=+2.8$，这是这位评委终身前 0.3% 的背书。传统软件只把它当成一条 3.65 的中评。

可靠度权重 $\rho_u$ = 该评委与长期共识的一致性 × 品类经验（同品类评论数）。
$$\hat z_v = \frac{\sum_u\rho_u z_{u,v}}{\sum_u\rho_u}$$

**3b. 客群错位（逆倾向加权到 Macheng 的目标客群）：**

客群特征 $c$ 包括：昼/夜（食べログ本身就分昼夜两个分）、支付价位、是否套餐、通りがかり 信号、评委常住地区、品类经验。
$$w_i = \text{clip}\Big(\frac{p_{\text{target}}(c_i)}{p_{\text{obs}}(c_i)},0.2,5\Big),\quad n_{\text{eff}} = \frac{(\sum w_i)^2}{\sum w_i^2}\ge 8\ \text{否则收缩}$$
$$\phi_{\text{cohort}} = \ell\Big(\frac{\sum w_i z_i}{\sum w_i}\Big) - \ell(\bar z)$$

walk-in 信号词：`たまたま` `通りがかり` `時間つぶし` `駅近で便利` `チェーン店かと思ったら` `ランチで軽く`。

**3c. 地区与品类基线：**
- 地区：$q = F_{\text{region},g}(S)$ 是店在本地区、本品类内的分位；$S^{\text{adj}} = F^{-1}_{\text{nat},g}(q)$ 换算成全国同分位对应的分数。例如福冈的寿司分数应换成东京寿司口径来读，具体折算从全量分布实测。
- 品类天花板：大衆酒場、おでん 的 3.5 在本品类里可能已是顶尖。默认它不进入跨品类总分，只显示为「品类内前 x%」徽章，以免把好酒场抬到怀石的档位。这是我定的默认，可以改。

### Factor 4：多模态视觉手艺 $\Delta_{\text{vision}}$

先修正一句话：照片不是不会撒谎，而是比文字难撒谎，但照片会被挑选。所以视觉信号必须做去挑选处理，并且全部用相对指标。

| 品类 | 可视手艺特征 | VLM 判定方式（相对 / 可信度） |
|---|---|---|
| 鮨 | 小肌 鹿の子包丁 网格规则度；烏賊 隠し包丁；大トロ 蛇腹；シャリ 粒立ち・赤酢色・ほどけ；ネタ艶、无 drip | 网格间距方差、断面光泽 |
| 炭火 | 皮目焦色均一度；断面 ロゼ 从边缘到中心的梯度；盘底肉汁面积（反映 ルポゼ 是否到位） | 只看焦层与肉厚的比例，不报绝对毫米数，VLM 量不准 |
| 出汁 / 拉面 | 一番出汁透明度；鸡白汤乳化均匀度；油膜粒径 | 先做光照归一（gray-world）再测透明度 |
| 生食 | ウニ 粒棱完整还是溶塌（明矾味只能靠文字判断）；鶏刺 断面半透明光泽 | 形状完整度 |

**数学定义。** 先求每张照片在每个评分项上的手艺分 $c_{p,j}\in[0,1]$ 和置信度 $\kappa_{p,j}$，再做时间衰减的稳健均值 $C_v$。关键是和同分档的期望手艺比较，不和绝对值比较：
$$\phi_{\text{vision}} = \lambda_v\big(C_v - \mathbb E[C\mid S_{\text{tabelog}}, g]\big)\cdot\mathbb 1[n_{\text{photo}}\ge 12,\ \text{拍摄者}\ge3,\ \text{拍摄日}\ge3]$$
结果是：手艺完美的 4.5 鮨店得 0，因为它本该如此；手艺达到 4.0 档的 3.4 小店才得正分。

**反作弊：**
- 排除店铺官方图。
- 多个账号之间 pHash 相同的图，视为店方分发，剔除。
- 饱和度超出品类 95 分位的，视为滤镜，降权。
- 照片必须跨越至少 3 个拍摄日。

### Factor 5：日本式隐性泡沫逆向过滤 $-\Delta_{\text{hype}}$

**① 常連・相互忖度（熟客与大 V 人情分）**
- 关系图：互相关注 + 同店同日（±1 天）共同到访 + 圈内互评高分。用社区发现找出密度 > τ 的子图。
- 文本标记：`ご招待` `レセプション` `試食会` `PR` `ご厚意で` `特別に出していただき` `大将にいつもお世話に` `〇〇さんにお誘いいただき`
- 计算：$\phi_{h1} = \max\big(0,\ \ell(\bar z_{\text{all}}) - \ell(\bar z_{\text{independent}})\big)$，即只用圈外独立评委重算后的差值。

**② キラキラ映え罠**
- 视觉：海胆、鱼子、金箔、鱼子酱、こぼれ 摆盘的面积占比记为 $Top_v$，与手艺分 $C_v$ 对照。
- 文本：`映え` `インスタ` `こぼれ` `SNSで見て` `サプライズ`；资深评委的拆穿词：`見た目重視` `味は普通` `ウニが溶けて` `ミョウバン` `シャリが崩れる` `ネタが冷たい`
- 计算：$\phi_{h2} = \lambda_h\max(0,\ Top_v - C_v)$

**③ 名店惯性（换厨师或搬店后的滞后虚高）**
- 文本：`代替わり` `大将が変わって` `二代目` `移転後` `以前ほどでは` `昔はもっと` `味が落ちた`
- 方法：对 $z_t$ 做贝叶斯在线变点检测（或 CUSUM），找到变点 $t^*$。
$$\phi_{h3} = \max\big(0,\ \ell(\bar z_{\text{all}}) - \ell(\bar z_{t>t^*}^{\text{半衰期 18 个月}})\big)$$

**示例（虚构店，说明计算过程）：** 某「肉寿司・ウニこぼれ」店，表面 3.75。圈外独立评委重算后 −0.20；$Top-C$ 差距 −0.15；2025 年疑似换厨师之后的评论再扣 −0.10。合计 3.75 → 3.30，可信区间 ±0.08。前端标 ⚠️「映え型」。

## 4. 验证闭环（不验证就不能称为「校准」）

1. **回测 A（预测力）。** 用 24 个月前的数据快照计算 $S_{\text{true}}$，看它预测「当下食べログ分 / 百名店入选」是否显著优于 $S_{\text{tabelog}}$。指标：Spearman 相关、AUC。某个因子没有带来增量，它的 $\kappa_k$ 就自动调大，相当于收缩掉。这一步专门检验它是否和食べログ自带的影響度加权重复。
2. **回测 B（泡沫识别）。** 被标为 hype 的店，后续 12 个月分数是否显著下跌。
3. **Owner 闭环。** Macheng 去过之后留一个 1–5 分加一句话，用来评估 `p_satisfy` 的 Brier 分数，并按偏好更新 $\omega_S$ 等权重。

**Anticipated 体感：** 第一批重算完成后，Macheng 应该看到连锁居酒屋的校准幅度降到 ±0.1 以内，被上调 0.3 以上的只剩少数有职人证据的小店，每一条上调点开都能看到日语原句或照片证据。反信号：上调普遍化（多数店都被抬高），或者某条瀑布拿不出原文证据。

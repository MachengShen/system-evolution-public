从世界底层原理，到我们想参与塑造的未来

一份不把物理学、意识研究、AI 工程与继承而来的定性解释框架混成“万物解释”的研究地图。它的重点不是给终极答案，而是让不同证据等级的主张可以被逐条检查、反驳和更新。

阅读时间约 13 分钟 · 中文首版 · 人类发起者与 AI 研究助手共同整理

90 秒抽象

“世界可以被编码”几乎不约束世界是什么。更强的问题是：什么物理结构规定了哪些状态、组合与变化真正可能？嵌入其中的系统又如何通过测量、记忆、预测和行动，改变自己可达的未来？

我们的工作假说：有因果意义的信息，不只是一段消息或一个比特数，而是对未来可达结构造成的可测改变。它目前是研究纲领，不是已建立的物理定律。

科学性协议

Reference 是必要条件，不是充分条件：来源必须真的支持旁边那句话，且仍要接受复现、反例与独立检验。

  1. 每条主张先标证据身份，再谈意义。
  2. 每个科学事实链接到原论文或权威学术条目。
  3. 类比不算验证；必须给出额外预测。
  4. 预测、愿望和干预分开记账。
  5. 提前写下什么结果会让我们改主意。

边界先说清：本页引用的信息论、量子重建、全息对偶与意识实验本身，都不能证明“宇宙本质就是信息”，也不能给出一套已收敛的意识理论。任何继承而来的定性框架——无论来自哲学、修行、术数、民间经验还是我们自己的新理论——都不会因历史悠久、主观强烈或术语相似而自动增加科学证据权重。[R1] [R4] [R5] [R10]

一条相连、但不混级的主线

下面是一张“主张—引用”图：箭头表示研究问题如何逐层收窄，不表示后一层已经被前一层证明。

  1. QUESTION 01

    世界为何允许这些可能性？

    终极本体未知。先要求候选理论说明允许的状态、组合、变换和限制。

  2. CONSTRAINT 02

    信息量不等于世界本身

    香农信息处理统计不确定性；信息处理也必须物理实现，但两者都不自动推出信息本体论。[R1] [R2]

  3. HYPOTHESIS 03

    信息＝可达未来的改变？

    把“有意义的信息”操作化为：干预后，系统未来可达状态或转移概率发生多少稳定变化。

  4. LEARNING 04

    记忆改变后续转移

    生物记忆会经历再巩固，相关 engram 与承载网络也会随时间变化；AI 则面对稳定—可塑性冲突。跨基底统一仍是假说。[R7] [R8] [R16] [R17]

  5. PROGRAM 05

    General Learning Machine

    让结果中的误差、价值与摩擦成为归因信号（credit），回到真正造成结果的模型、记忆、工具、规则和组织环节。

旁线案例：整类传统或神秘解释框架都可以进入同一套检验；五行、八卦只是其中两个例子。先拆出明确结构，再判断它是经验残留、生成隐喻、社会 / 仪式技术，还是无法证伪的后加解释。

⇢

同一把尺：我们的“可达未来”与 GLM 也不享受特权。只有明确构念与映射、胜过匹配基线、做出样本外新预测、带来干预增益且可复现，才可能从故事升级为模型。

七种身份，七种说话方式

已建立证据高

信息论能量化通信约束，但把语义放在模型之外

香农理论给出了熵、信道与可靠传输的数学框架；原论文明确把消息的语义层面限定在该通信工程问题之外，因此它没有把“意义”或“存在”还原成比特。[R1]

越界信号：从“可以用比特描述”直接跳到“实在就是比特”。

证据 + 模型边界高 / 有限域

逻辑不可逆操作受物理耗散约束，但这不是本体证明

Landauer 将逻辑不可逆操作与最低耗散联系起来；受控实验验证了单比特擦除的相应热力学下界。结论约束这类操作的物理实现，不等于“物质由信息生成”。[R2] [R3]

越界信号：把每个计算门都说成固定支付同一能量，或把热力学约束改写成本体优先级。

形式模型 / 解释领域内强，外推弱

信息原则与对偶能强约束形式，但本身不裁定本体

Chiribella 等人在明确的一组公理下重建有限维量子理论；Maldacena 的工作则在特定理论与边界条件下提出 AdS/CFT 对偶。两篇论文都没有把其数学结果声明为一套被唯一证明的“信息本体论”。[R4] [R5] 另有操作框架把全局因果顺序也变成待研究结构，而不是预设背景；这仍是理论可能性，不等于日常因果性虚幻。[R6]

越界信号：把特定对偶写成“任何三维世界都由二维比特投影”。

模型 → 我们的假说0.45

“未来可达性”可能比“消息内容”更接近统一变量

定义系统状态 (x)、允许干预 (a) 与转移核 (P(x'|x,a))。工作假说把信息的重要性放在它对这个转移结构造成的反事实改变，而非文本长度或主观震撼。

反信号：它无法给出跨粗粒化稳定的量，或对预测、控制与记忆更新没有增量解释力。

证据 → 工程移植证据高 / 移植 0.55

记忆不是仓库；但“记忆即动力学”仍是跨域提案

神经科学中的再巩固、系统巩固与 engram 研究表明，记忆再激活后可重新进入可塑状态，承载网络与表征也会随时间变化；持续学习研究则展示了新学习损伤旧能力的问题。把这些统一成 agent 的“可塑拓扑”是工程假说，不是神经机制的复制品。[R7] [R8] [R16] [R17]

反信号：记忆系统越来越复杂，却不减少重复纠正、不改善迁移、也无法回滚。

边界模型 / 未决0.40

“自我边界”应由干预识别，而不是由漂亮的读数命名

发育生物学已有把多细胞协调边界当作计算性“自我”来研究的纲领；它提供可检验的控制视角，但不证明任意闭环都有主观体验。[R9] 2025 年的预注册对抗性实验中，部分结果符合 IIT 与 GNWT 的预测，同时实质挑战了两者的关键主张。[R10]

反信号：边界指标在切开、合并、迁移系统成员时不随因果整合发生可重复变化。

Macheng + Agent 假说0.40

GLM：把 credit 从权重层扩展到整个因果栈

未来误差、惊讶、价值、摩擦与可持续性压力，不只更新模型参数，也应更新记忆索引、工具路由、验证规则、协作结构与硬件放置。这是一个可造、可失败的系统假说，而不是“通用智能已经解决”。

反信号：更多反馈通道只制造流程与日志，没有带来更好的校准、更少的人工盯守或更强的跨任务迁移。

目标 + 干预价值选择

目标不是“更自主的 AI”，而是“更有能动性的人”

我们希望个人拥有可迁移的记忆、模型选择权、动作权限和退出权；公开这张图本身是一项干预：把讨论从不可核验的宏大叙事，拉向带来源、反信号和修订记录的共同研究。

停止条件：系统以“替人做主”换取表面效率，或者公开叙事开始压迫异议而不是吸收异议。

传统 / 神秘解释框架里，什么可能是真结构，什么只是低精度或主观加料？

研究对象不是五行或八卦本身，而是整类继承而来的定性框架：哲学范畴、修行地图、术数、民间分类、仪式体系与长期经验总结。我们既不因其非现代而先验排除，也不因其古老、完整或“很有体感”而降低验证门槛。

A · 经验残留待拆解

长期观察可能留下了真实但低分辨率的规律

一个传统分类也许压缩了季节、身体状态、生态互动或群体行为中的重复模式；但原标签通常把多种变量捆在一起。研究任务是把“似乎有效”拆成可测构念、适用人群、时间尺度、环境条件与误差范围，而不是直接保留整套解释。

降级条件：拆开后没有稳定信号，或效果完全由选择性记忆、共同原因、回归均值和事后分类解释。

B · 生成隐喻可有用，不等于为真

好的隐喻能生成问题，不能代替答案

有限类别、对立互补、循环生克、层级转化等结构，可能帮助研究者提出新的状态空间、关系图或干预候选。其价值由“是否生成此前没有的新假设”衡量；术语与现代模型相像，只是发现候选映射的起点。

降级条件：同一隐喻能事后适配任何结果，或换一套任意标签也产生同样洞见。

C · 社会 / 仪式技术功能与宇宙论分开

一个框架可能“有用”，却不是因为它描述了宇宙底层

共同叙事、仪式节律、角色命名与注意力训练，可能通过协调预期、情绪、身份或群体行动产生实际效果。这里应测量行为与社会机制、收益与伤害、谁在何种条件下受益；功能证据不能倒推其超自然解释为真。

边界条件：效果若依赖权威压力、排斥异议、无法退出或把失败归咎于参与者，就应作为风险而不是“深奥”保留。

D · 不可证伪的后加解释不承载科学结论

解释失败后无限补丁，不再是承担风险的模型

若每次反例都能靠隐藏变量、临时改义、只挑命中案例或“你还没领悟”被吸收，这部分也许仍有文学、身份或个人意义，但不能继续以经验事实或预测模型的名义承重。

杀死条件：事前不能列出任何可能降低置信的观察；或不同解释者对同一案例无法得到稳定编码。

对称测量协议传统与新理论同门槛

“解释力”必须变成一组可以输的比较

① 构念与映射：符号对应哪些可测变量，变换规则是什么？
② 压缩：在预先约定的误差下，是否比等复杂度基线用更短描述覆盖更多规律？
③ 新预测：是否在未见样本、预留时间段或新群体上给出方向与幅度？
④ 干预杠杆：依规则行动是否比随机、常识或数据驱动基线更能改变结果？
⑤ 稳定性：不同研究者能否复现编码与结论；涉及体验时，量表、访谈编码与生理 / 行为指标是否有跨时间稳定性？
⑥ 边界与退出：在哪些尺度、人群、情境失效；什么结果会撤回映射？

对我们自己同样适用：“未来可达性”若不能在压缩、样本外预测或控制上胜过普通状态空间模型，就降回启发式；GLM 若不改善校准、迁移与可逆性，就撤回其统一性主张。

主观体验的地位数据，不是单独的证明

体感不是零价值，也不是免检通行证

第一人称体验可以提示现象、定义待解释对象并生成实验，但需要明确采样、盲法或对照、重复测量、报告偏差控制和跨解释者编码。它可以是重要数据的一部分；仅凭强烈、神圣或难以言说的感受，不能单独证明外部因果结构或宇宙本体。

双向反信号：若客观指标暂时捕捉不到体验，不应直接宣布体验不存在；若体验叙述无法区分互相冲突的外部理论，也不能拿它裁定哪套理论为真。

示例，不是中心可运行前待预注册

五行 / 八卦只是可送进协议的两个案例

《易经》的阴阳线、八卦与六十四卦，以及五行的生成、制约与转化，可分别提出组合空间和有向关系图的候选映射。[R11] [R12] 例如：用五行关系图事先约束一个时间序列的状态转移，再与等参数随机图、Markov 模型和数据驱动基线盲测。只有样本外预测或控制稳定占优，才继续研究该映射；否则保留其历史、隐喻或社会功能，撤掉科学增量主张。

禁用跳跃：“量子比特证明了阴阳”“五行就是五种基本力”“八卦预言了 AI”。

未来世界：预测、目标、干预分开

下面不是预言。概率是作者先验，而非由引用直接计算出的统计概率。2026 年国际独立科学评估记录了 agent 能力与自主性的上升；NIST 的在研项目则把事实落地、引用核验和机器可读审计轨迹列为测评方向。[R13] [R14]

F1 · Agent 治理会明确要求动作审计

截至 2030-12-31，下列五个公共机构体系中至少三个发布专门面向可自主行动 AI（agentic AI）的正式规范或指导，并明确要求或建议保留机器可读的工具调用、授权与结果记录：NIST、ISO/IEC JTC 1/SC 42、OECD.AI、欧盟 AI Office、英国 AI Security Institute。作者先验 0.75；基准理由是现有国际评估与 NIST 在研项目已经把自主行动和可追溯测评列为缺口，而非从它们直接推导 0.75。[R13] [R14]

结算：在截止日按五个机构的官方文档库逐一归档；达到 3/5 即命中，2/5 以下即未命中，机构改名则沿法定继承机构追踪。
反信号：到 2028-12-31 仍少于两个体系发布此类要求。

F2 · 接口从对话框变成持续系统

截至 2030-12-31，下列六个产品家族中至少四个在其官方文档中同时提供：跨会话记忆、后台或定时任务、工具执行、跨设备任务状态同步——ChatGPT、Claude、Gemini、Microsoft Copilot、Apple Intelligence / Siri、Meta AI。作者先验 0.70；基准理由是 agent 自主性上升的当前趋势，概率仍是本项目判断。[R13]

结算：以截止日前最后一个公开稳定版的官方文档为准；产品改名但账户与状态连续则沿继承产品追踪，每个家族四项全有才计 1。
反信号：到 2028-12-31 仍没有两个家族满足四项。

T1 · 用户拥有自己的能动性底座

这不是预测。我们希望记忆、权限、模型路由、审计与退出权围绕用户组织；模型提供商可替换，用户的连续性不随提供商消失。

受益者：普通个人与小团队。
风险：复杂度、隐私泄漏、自主系统越权与新的平台锁定。

I1 · 把公开研究变成代谢

持续发布带状态、引用、反信号和修订记录的主张，邀请外部读者找错；把有效批评转化成实验、规则更新或撤回。问题默认匿名，只有经提出者明确同意才署名。

闭环：公开版本 → 问题收录 → 证据审计 → 只保留必要内容的修订记录。
停止：公开只增加传播，不增加纠错或可复现性。

如何保证它不滑向“什么都能解释”

  1. 先定状态。
    事实、模型、解释、假说、隐喻、预测、目标、干预不可混写。
  2. 再定承重来源。
    优先原论文、官方标准、正式学术条目；二手内容只作为入口。
  3. 登记反信号。
    先写什么观察会降低置信，避免结果出来后无限补丁。
  4. 保留修订史。
    治理、测试、评估、验证与确认要覆盖系统全生命周期；撤回不是失败。[R15]

我们仍然不知道什么

不知道宇宙是否存在唯一“底层材料”；不知道信息结构是不是本体、描述语言或二者在某种对偶下的等价表达；不知道主观体验需要什么充分条件；不知道“未来可达性”能否成为跨物理、生物与 agent 系统的稳定不变量；也不知道任何传统定性框架的现代映射能否在压缩、样本外预测或干预上胜过匹配的普通基线。

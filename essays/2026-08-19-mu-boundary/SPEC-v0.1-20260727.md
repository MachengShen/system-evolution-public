## §0 一句话:这个实验在赌什么

赌**通道归属变量 $m_i$ 的动力学存在双稳**,且双稳**不是手装的**,而是从「闭包 + 精度门控」里长出来的。
若手装才有 ⟹ 退化成一个启发式 latch,不是范式。这是唯一真 wedge,其他都是配套。

**Host-coupling(fleet 默认条款)**:本项目不需要任何 macOS 独占面(Keychain/Photos/AppleScript 等均不涉及),MuJoCo viewer 可离屏渲染 ⟹ **应跑在 AWS fleet 上,headless**。本机 M5 只作交互调试。

## §1 形式化对象

### 1.1 通道 (channel)

世界以固定的 $N$ 条**标量传感-运动通道**暴露给学习器,$c_i(t)\in\mathbb{R}$,$i=1..N$。
μ 是**通道集合上的划分**,所以通道必须是**可个体化、身份稳定**的东西。

> ⚠️ **memo 藏起来的硬约束**:原始像素**不能**当通道。"像素 (12,7) 属于 self"没有意义,因为指称物会移动。μ 的载体必须是 entity-like 的槽位。
> 解法三选一:(a) 仿真里直接用特权 entity 列表(phase 0 推荐,先把滞回问题隔离出来);(b) Slot Attention / 跟踪关键点;(c) 只用本体感+触觉,不用视觉(最保守)。
> **未验证设计选择**:phase 0 走 (a)。这会被批评为「视觉问题被回避」——接受,因为本实验的生死不在视觉。

最小 rig 的通道表(共 $N=34$):

| 组 | 数量 | 内容 |
|---|---|---|
| 本体感 | 9 | 3 关节角 + 3 关节角速度 + 3 电机电流(实际施加力矩读数) |
| 触觉 | 10 | 8 臂上 taxel + 2 工具尖端 taxel |
| 视觉(关键点) | 12 | 6 个标记点 × 2 维平面坐标(3 在臂上,1 工具根,1 工具尖,1 外部干扰球) |
| 动作回读 | 3 | 3 个指令力矩(**不预设为 self**,因为 falsifier #2 要求断掉的执行器能被踢出 self) |

**关键**:干扰球必须被一个 agent 无法控制的外力(伪随机风场)驱动。否则「world」这一类在数据里没有可辨识的签名,划分欠定。

### 1.2 μ 的数据结构

$$\mu(t) = \{m_i(t)\}_{i=1}^N,\qquad m_i(t)=\mathrm{softmax}(\ell_i(t)/\tau_m)\in\Delta^2 \ \ \text{over}\ \{S,B,W\}$$

即每通道一个 **3 分量软归属**(self / blanket / world),由 3 维 logit $\ell_i$ 经 softmax 得到。

**为什么是三分而不是 task 里建议的标量 $m_i\in[0,1]$**:blanket 条件 $W\perp S\mid B$ 本质上是三元关系,标量无法表达"我是屏障"这个第三态。可以用 2 个 logit(固定 $\ell^W_i=0$)省参数,但推荐保留 3 个 logit 让梯度对称。

**最重要的架构承诺(整份规格的地基)**:

> $\ell_i$ 是一个 **ODE 状态变量**,按时间积分;**不是**任何网络的前馈输出 $m=g_\theta(\text{obs})$。

前馈参数化在结构上无记忆 ⟹ 结构上不可能有滞回 ⟹ 就是 memo 要杀的 Φ-argmax。这个选择**本身就是论文的主张**,不是实现细节。

> **诚实的 prior art 增补(memo 未列)**:`arXiv:2502.21217` *Dynamic Markov Blanket Detection for Macroscopic Physics Discovery*(2026-02)已经做了「用变分贝叶斯 attention 给每个微观元素动态打 internal/boundary 标签」,实验含 Newton's cradle / 燃烧引信 / Lorenz / 模拟细胞。**这是目前离本提案最近的东西,比 memo 列的任何一条都近。**
> 我的判断(**基于摘要,未核实正文**):它的标签是**每步重算的后验**,时间连续性来自 HMM 类平滑先验 = 一阶低通,不是双稳;摘要无 hysteresis/bistability 字样。⟹ 我们的 wedge 仍在,但**变窄了**:不再是"动态 μ",只剩"μ 的双稳/滞回"。**跑实验前必须读正文确认**;若它已含双稳,本线应直接终止或重定位。

### 1.3 状态 z 与编码器

$$z_t \in \mathbb{R}^{d_z},\ d_z=32$$

编码器是**置换等变的集合编码器**(不是固定维度 MLP),这样通道增删(工具接上、执行器断掉)不需要改架构:

$$e_i = \mathrm{MLP}_\phi\big([\,\mathrm{win}_H(c_i),\ \text{id-embed}_i,\ m_i\,]\big),\qquad
z_t = \mathrm{AttnPool}\big(\{(m^S_i+m^B_i)\cdot e_i\}_i\big)$$

其中 $\mathrm{win}_H$ 是长度 $H{=}8$ 的通道历史窗口。**world 通道被门控掉,不进 z**——这就是让 μ 真正有后果的地方:选错划分,z 就没法闭合。

编码器输出高斯参数 $(\mu_z,\sigma_z)$ 供 §2 的 VIB 项使用(重参数化采样)。

潜动力学:$\hat z_{t+1}=f_\psi(z_t,a_t)$,$f_\psi$ 用 3 层 MLP 或 GRU(推荐 GRU,便于多步展开)。

### 1.4 动作

Phase 0 **不学策略**。动作 = 固定的 OU 相关噪声 babbling(相关时间 0.5 s)。理由:滞回必须在没有策略学习的情况下出现,否则无法归因。策略学习是 phase 2 的事。

## §2 损失函数

记号:$\mathrm{sg}[\cdot]$ = stop-grad;$\bar\phi$ = 编码器 EMA 影子权重(动量 0.99)。

### 2.1 闭包违反 $\mathcal{L}_{\text{clo}}$(核心)

「z 是 state ⟺ 动力学在 z 上闭合」的可微量化 = **多步潜预测误差**(JEPA 式,无解码器):

$$\mathcal{L}_{\text{clo}}=\frac{1}{K}\sum_{k=1}^{K}\frac{\big\|\hat z_{t+k}-\mathrm{sg}[\,E_{\bar\phi}(c_{t+k},m_{t+k})\,]\big\|_2^2}{d_z},\qquad K=8$$

**已知偏差 / 失败模式**:
- **表征坍缩**:$z\equiv\text{const}$ 使损失为 0。必须加反坍缩项。
- **慢特征退化**:EMA-target 潜预测已知会只学最慢的变量(极端情况学到 episode 索引)。

反坍缩用 **VICReg**(不用 InfoNCE):

$$\mathcal{L}_{\text{var}}=\sum_{j=1}^{d_z}\max\!\big(0,\ \gamma_v-\sqrt{\mathrm{Var}(z_j)+\epsilon}\big),\qquad
\mathcal{L}_{\text{cov}}=\frac{1}{d_z}\sum_{j\neq k}[\mathrm{Cov}(z)]_{jk}^2$$

**为什么不用 InfoNCE 做反坍缩**:我们的 batch 在时间上强相关,同 episode 内的负样本会让模型靠「时间索引」这条捷径分辨正负,得到虚假高互信息。VICReg 无需负样本。
**VICReg 自身偏差**:方差下限只强制"维度被用上",**不保证预测充分性**;它能制造"看起来有信息"的表征。

对抗慢特征退化,加一条把 z 锚到可观测内容的项——它同时**就是 blanket 的定义**:

$$\mathcal{L}_{\text{blk}}=\mathbb{E}\Big[\textstyle\sum_i m^B_i\,\big\|\hat c_i(t{+}1)-c_i(t{+}1)\big\|^2\Big]$$

副作用是**想要的**:把通道放进 B 就必须预测它 ⟹ B 有代价 ⟹ 划分不会平凡地"全是 blanket"。

### 2.2 「最大化遗忘 s.t. 闭包」的拉格朗日形式

约束问题:

$$\min_{\phi,\psi,\mu}\ I(z_t;c_{\le t})\quad\text{s.t.}\quad \mathcal{L}_{\text{clo}}\le\epsilon_{\text{clo}}$$

拉格朗日 + 对偶上升(这样你调的是**可解释的容差** $\epsilon$,不是玄学权重):

$$\mathcal{J}=I_\theta(z_t;c_{\le t})+\lambda\big(\mathcal{L}_{\text{clo}}-\epsilon_{\text{clo}}\big),\qquad
\dot\lambda=\eta_\lambda\big(\mathcal{L}_{\text{clo}}-\epsilon_{\text{clo}}\big),\ \ \lambda\ge 0$$

$I(z;c)$ 的估计器 = **VIB 变分上界**:

$$I(z_t;c_{\le t})\ \le\ \mathbb{E}_{c}\big[\mathrm{KL}\big(q_\phi(z|c)\,\|\,r(z)\big)\big],\qquad r=\mathcal{N}(0,I)$$

**估计器选择的关键论证(别搞反)**:我们在**最小化** $I$。InfoNCE 和 MINE 都是 MI 的**下界** ⟹ 最小化一个下界是**空的**(vacuous),下界可以任意松而目标毫无约束。必须用**上界** ⟹ VIB。
**VIB 已知偏差**:仅当 $r$ 匹配聚合后验时才紧;固定单位高斯先验会**过度惩罚**并诱导轴对齐剪枝。对我们(想要剪枝)可接受,但**报告出来的"比特数"不是有效的 MI 估计,只能当上界报**。

### 2.3 Blanket 条件 $W\perp S\mid B$ 的可算代理

**(a) 主代理 — peek gain(预测残差差分 / Granger 式条件互信息)**:
训练一个**额外**能看到 world 通道的预测器 $f^+$:

$$\Delta_{\text{peek}}=\mathcal{L}_{\text{clo}}-\mathcal{L}^{+}_{\text{clo}}\ \ge 0,\qquad
\mathcal{L}_{\text{blk-cond}}=\max\!\big(0,\ \Delta_{\text{peek}}-\delta\big)$$

语义:若把 world 通道加回来能显著改善对 self 未来的预测,说明 blanket 没挡住 ⟹ 罚。
**已知偏差**:$\Delta_{\text{peek}}$ 是 CMI 的**下界**,且强依赖 $f^+$ 的容量——**欠拟合的 $f^+$ 会让 blanket 条件看起来成立**(假阳性)。
**缓解(方向必须保守)**:给 $f^+$ **比 $f$ 更大的容量和更多训练步**,并在冻结 μ 后训到收敛再报数。宁可高估泄漏。

**(b) 次代理 — 条件 InfoNCE**(仅 eval 期、冻结 μ 时跑,不进训练回路):在 $b_t$ 分箱内重采样负样本估 $I(s_{t+1};w_t\mid b_t,s_t)$。
**已知偏差**:分箱维度诅咒 + InfoNCE 上限 $\log(\text{batch})$;batch=256 时饱和在 5.5 nats。只能用于「有没有明显泄漏」的粗判。

### 2.4 μ 的塑形项

- **blanket 成本**:$\beta_B\sum_i m^B_i$(否则一切都变 blanket)。
- **可控性增益(工具并入的物理信号从这里进来)**:

$$g_i=\underbrace{\mathbb{E}\big\|\hat c_i(t{+}1)\mid z_t\big\|_{\text{err}}}_{\text{不看动作}}-\underbrace{\mathbb{E}\big\|\hat c_i(t{+}1)\mid z_t,a_t\big\|_{\text{err}}}_{\text{看动作}},\qquad
\mathcal{L}_{\text{ctrl}}=-\gamma_c\sum_i m^S_i\,g_i$$

$g_i$ = 动作对通道 $i$ 的预测增益(empowerment 的廉价版),在 $m$ 上是**线性**的 ⟹ 梯度干净。
**这就是「握住工具时工具获得、松手时失去」的那个量**。整个滞回现象最终挂在 $g_{\text{tool}}$ 随握持刚度的变化上。

### 2.5 总目标与 μ 的驱动力

$$\boxed{\ \mathcal{J}_{\text{total}}=\lambda\mathcal{L}_{\text{clo}}+\mathcal{L}_{\text{blk}}+\beta_I\mathcal{L}_{\text{VIB}}+\alpha\mathcal{L}_{\text{blk-cond}}+\beta_B\!\sum_i m^B_i-\gamma_c\!\sum_i m^S_i g_i+\mathcal{L}_{\text{var}}+\mathcal{L}_{\text{cov}}\ }$$

**μ 不用这个损失做反向传播更新**。它只从中取出**每通道驱动力**:

$$u_i(t)\ =\ -\,\frac{\partial \mathcal{J}_{\text{total}}}{\partial \ell_i}\Big|_{t}\quad(\text{单步、detach、不进优化器})$$

然后交给 §3 的动力系统去积分。**这是「不是 optimizer,是动力系统」这句姿态的具体兑现**:梯度只提供瞬时力,轨迹由 ODE 决定。

默认超参(**全部是未验证设计选择**):$\epsilon_{\text{clo}}{=}0.05$,$\beta_I{=}10^{-3}$(对偶自适应),$\alpha{=}1$,$\beta_B{=}0.02$,$\gamma_c{=}1$,$\gamma_v{=}1$,$\tau_m{=}1$。

## §3 滞回机制(本规格的核心)

### 3.1 降维:每通道一个序参量

把 3 维 logit 约化到标量**自我度** $x_i\in\mathbb{R}$:$\ell^S_i=x_i$,$\ell^B_i=\beta_0-|x_i|$,$\ell^W_i=-x_i$。
(即:$x$ 大 → self,$x$ 小 → world,中间 → blanket。**未验证设计选择**;这个 1-D 约化让解析分析可行,若实验显示 B↔W 的转移需要独立自由度,再升回 2-D。)

### 3.2 μ 的动力学(两个滞回来源,都要实现)

$$\boxed{\ \tau_x\,\dot x_i \;=\; \underbrace{b\,x_i-a\,x_i^3}_{\text{H-A: 显式双阱}}\;+\;\underbrace{\kappa\,\pi_i(t)}_{\text{H-B: 精度门}}\,u_i(t)\ }$$

$$\pi_i(t)=\pi_0+\Delta\pi\cdot\sigma\!\big(x_i/\tau_\pi\big),\qquad \text{或}\quad \pi_i(t)=\frac{1}{1+\varepsilon_i(t)/\varepsilon_0}$$

$\varepsilon_i$ = 通道 $i$ 的滑动预测误差。两种写法等价地实现同一个环:

> **self-seal 回路**:$x_i\uparrow$ ⟹ 通道 $i$ 进入 z 的预测目标 ⟹ 它被预测得更好 ⟹ $\varepsilon_i\downarrow$ ⟹ $\pi_i\uparrow$ ⟹ 驱动被放大 ⟹ $x_i\uparrow$。

这是**状态相关耦合**(state → coupling → state),memo 要的东西在这一行里。

**两个来源必须分开实现、分开消融**:

| | 机制 | 双稳来源 | 科学地位 |
|---|---|---|---|
| **H-A** | 立方项 $-ax^3+bx$ | 手装的双阱 | **positive control**。会被批评"你把答案写进去了"。用来验证测量协议能看见滞回。 |
| **H-B** | 精度-归属正反馈 | 学习动力学涌现 | **真正的主张**。$a=0$ 时是否仍双稳,就是 falsifier #1。 |

### 3.3 双稳存在的参数条件(可验算)

**H-A(尖点突变标准形)**:把慢变驱动当作外场 $h$(即 $\kappa\pi u\to \kappa h$),不动点解

$$a x^3 - b x = \kappa h$$

三根实根(⟹ 双稳)的条件由判别式给出:

$$\boxed{\ b>0\quad\text{且}\quad |h| < h_c=\frac{2}{\kappa}\sqrt{\frac{b^3}{27a}}\ }$$

- **滞回环在驱动轴上的宽度** $=2h_c=\dfrac{4}{\kappa}\sqrt{b^3/(27a)}$;
- **跳变点**在 $x=\pm\sqrt{b/(3a)}$(鞍结分岔处);
- 标度律:宽度 $\propto b^{3/2}a^{-1/2}$。

数值锚点(推荐起始参数):$a{=}1,\ b{=}1,\ \kappa{=}1$ ⟹ $h_c\approx0.385$,跳变在 $x\approx\pm0.577$。
**验收**:数值积分必须复现这两个数(误差 <5%),否则实现有 bug。这是最便宜的单元测试。

**H-B(涌现版,自洽方程的环增益判据)**:设漏项 $-\gamma x$,驱动 $u\approx(g-c)$(并入的收益减成本,近似常数),则

$$\gamma x^* = \kappa\,\pi(x^*)\,(g-c),\qquad \pi(x)=\pi_0+\Delta\pi\,\sigma(x/\tau_\pi)$$

在中点 $\sigma'=1/(4\tau_\pi)$,**出现三个自洽解(双稳)的充要条件是环增益 > 1**:

$$\boxed{\ G=\frac{\kappa\,\Delta\pi\,(g-c)}{4\,\gamma\,\tau_\pi}\ >\ 1\ }$$

**这条不等式是整条线的生死判据**,而且**其中 $\Delta\pi$ 是可以先测出来的经验量**(self 通道与 world 通道的预测精度对比)。见 §7 的 D1。

**并入慢 / 释放更慢的非对称从哪来**(memo 断言了但没给机制):
对称双阱给出的是**关于倾斜对称**的阈值,不自动产生 on/off 非对称。非对称正是 $\pi_i$ 提供的:**已在 self 内的通道精度更高 ⟹ 它的证据权重被放大 ⟹ 反向证据要更大才能把它赶出去**。所以

> **精度门不是自由参数,它就是产生「进来容易出去难」的那个机制。** 若实现里把 $\pi$ 设为常数,非对称应当消失——这是一条独立的、比 falsifier #1 更细的预测。

另注:memo 把**阈值非对称**和**时间常数非对称**混为一谈。它们是两个不同的量,必须分开测(§5.7)。

### 3.4 消融:「拿掉非线性 → 滞回消失」怎么做

三档对照(同数据、同种子、同训练预算):

| 档 | $x$ 的更新律 | 预测 |
|---|---|---|
| **A 全非线性** | $\tau\dot x=bx-ax^3+\kappa\pi(x)u$ | 环面积外推到零扫速仍 >0 |
| **B 线性 ODE** | $\tau\dot x=-\gamma x+\kappa\bar\pi u$($a{=}0,\ b{=}-\gamma<0,\ \pi\equiv\bar\pi$) | 唯一不动点 ∀h;环面积 $\propto$ 扫速,零扫速外推 = 0 |
| **C 前馈 argmax** | $m=\mathrm{softmax}(g_\theta(\text{window}))$,无状态 | 无环;边界处 chatter;工具切换性能最差 |

B 是"去掉非线性"的正确写法:**只把 $a$ 置零是不够的**——那样 $b>0$ 会让系统发散。必须同时把 $b$ 翻号成漏项,才是干净的一阶线性滤波器。这是一个容易写错的实现细节。

### 3.5 μ 积分器伪代码

```python
# 每个控制步 (50 Hz)。x: [N] 慢变量; eps: [N] 滑动预测误差
u = -autograd.grad(J_total, logits, retain_graph=False)[..., S_IDX].detach()  # [N]
pi = pi0 + dpi * torch.sigmoid(x / tau_pi)          # H-B 精度门 (或用 1/(1+eps/eps0))
dx = (b * x - a * x**3) + kappa * pi * u            # H-A + H-B
x  = x + (dt / tau_x) * dx
x  = x.clamp(-X_MAX, X_MAX)                         # 防数值爆炸, X_MAX=3
logits = torch.stack([x, beta0 - x.abs(), -x], -1)  # §3.1 的 1-D 约化
m = torch.softmax(logits / tau_m, -1)               # 下一步喂给编码器
```

时间尺度**必须**满足(否则整个测量无意义,见 §5.4):
$$\tau_{\text{obs}}\ \ll\ \tau_x\ \ll\ T_{\text{sweep}}$$
默认 $\tau_{\text{obs}}\approx0.1\,\mathrm{s}$,$\tau_x=2\,\mathrm{s}$,$T_{\text{sweep}}=100\,\mathrm{s}$。

## §4 可跑的最小实验规格

### 4.1 仿真栈:**MuJoCo 3.10.x,CPU,原生 Python 绑定**

三条理由(**不是** MJX,**不是** Genesis,**不是** Isaac):

1. **吞吐不是瓶颈**。3R 平面臂 + 几个刚体,无网格碰撞,CPU MuJoCo 在 M5 上约 $10^5$ step/s;一个 500 控制步的 episode ≈ 10 ms。瓶颈是学习不是仿真。为不需要的吞吐引入 JAX 是负收益。
2. **`eq_active` 在 MJX 上有已知问题**(google-deepmind/mujoco issue #2173:MJX 忽略 `eq_active`)。可拆工具**就是**靠 weld equality 的运行时开关实现的 ⟹ 直接排除 MJX。社区推荐做法:**在 XML 里预先声明 weld,初始 `active="false"`,运行时改 `data.eq_active[k]`**(不要用 MjSpec 动态添加——那样不会自动算 q0 处的偏移量)。
3. **Genesis 2026 年仍非主流默认**,其 10–80× 提速是对 Isaac、且疑似对比单线程 MuJoCo;多物理场(软体/流体)我们用不上。不为新鲜付调试税。

版本锁:`mujoco==3.10.0`(2026-06 发布),`torch>=2.8`。

### 4.2 机械与传感配置

```
平面 3R 臂(重力在平面内),link 长 0.25/0.20/0.15 m
  joint j1,j2,j3 —— 力矩执行器,gear=1,ctrlrange ±3 N·m,50 Hz 控制,dt=0.002(frame_skip=10)
  8 个 taxel:每 link 2 个上表面 2 个下表面(touch sensor)
  末端 site "hand"
工具:自由刚体 rod,长 0.30 m,质量 0.15 kg,尖端 2 个 taxel
  与 hand 的 weld equality(XML 预声明,active=false)
  ★ 握持强度是连续参数:通过 eq 的 solref = (tau_ref, damp_ref) 调节有效刚度 k_grip
干扰球:自由刚体 ball,被伪随机风场(OU 力)驱动,agent 无法控制
       会偶尔与臂碰撞(⟹ 相关但不可控,正是 world 的定义性签名)
相机:phase 0 不用像素,直接读 6 个标记点的平面坐标
```

**可拆工具的建模要点**:
- **不要做成二值 attach/detach**。滞回测量需要一个**连续可扫的控制参数**。
- 实现:weld 常开,但 `solref` 的 $\tau_{\text{ref}}$ 从很软($10^{-1}$,几乎无约束)扫到很硬($2\times10^{-3}$)。
- ⚠️ **未验证设计选择**:MuJoCo `solref` → 有效刚度的映射是软约束参数,不是牛顿刚度。**必须先标定**:施加已知横向力,测手-工具相对位移,反解等效 $k_{\text{grip}}$,把它作为横轴。**不要拿 solref 的原始数字当横轴画图。**
- 备选实现(若 solref 标定不干净):用一对位置伺服"夹爪"以可控法向力压住工具,靠库仑摩擦产生自然滑移。物理更真实,但引入接触抖动。

**可断执行器的建模要点** —— 两种损伤要**分开**做,它们预测**不同**的 μ 重划分:
- **运动性损伤(不能动,仍能感)**:`model.actuator_gainprm[j,0]=0`,并加大 `dof_damping[j]`。预测:$g_j\to 0$ ⟹ 该关节从 S 掉向 B/W。
- **感觉性损伤(能动,读数变噪声)**:该通道读数替换为独立高斯噪声。预测:该通道预测误差爆炸 ⟹ $\pi\downarrow$ ⟹ 被踢出 S,但**动作通道仍留在 S**。
这两种解离是很强的特异性证据,memo 里没有,建议纳入。

### 4.3 Episode 结构

| 阶段 | 时长 | 内容 |
|---|---|---|
| A 基线 | 20 s (1000 控制步) | 无工具自由 babbling。μ 应收敛:关节/电流→S,taxel→B,球标记→W |
| B 扫描 | $T_{\text{sweep}}$ (可变) | $k_{\text{grip}}$ 上扫 → 保持 → 下扫。记录 $m^S_{\text{tool-tip}}(t)$ |
| C 损伤 | 60 s | 随机时刻施加运动性或感觉性损伤,量重收敛时间 |
| D 探针 | 30 s | 下游探针任务(把工具尖送到目标点),仅用于与 BC baseline 比较 |

### 4.4 训练规模与算力

- **模型**:通道编码 MLP $34\!\to\!64$,注意力池化 → $z\in\mathbb{R}^{32}$;GRU 动力学 3×256;$f^+$ 加大 2×。合计 **1–3 M 参数**。
- **数据**:预训练 2000 episodes × 500 控制步 ≈ $10^6$ transitions。
- **梯度步**:$2\times10^5$,batch = 64 序列 × 32 步。
- **两阶段调度(重要,别跳)**:
  1. **冻结 μ**(初始化为均匀 + 小噪声)训编码器/动力学 $5\times10^4$ 步。理由:$\pi_i$ 依赖预测误差,预测器是垃圾时精度信号无意义,μ 的 ODE 会骑在噪声上跑出假双稳。
  2. 解冻 μ,在线积分,继续 $1.5\times10^5$ 步。
- **算力结论**:**单卡绰绰有余,甚至不需要卡**。一张 A10/4090 上 < 1 h;M5 的 MPS 上数小时。
  **红线:如果这个实验需要超过一天的单卡时间,说明你把它做大了,回头砍。** 整份规格的价值就在于它便宜。

## §5 测量协议:滞回曲线怎么测

### 5.1 扫描什么控制参数

| 优先级 | 参数 | 范围 | 备注 |
|---|---|---|---|
| **主** | 握持有效刚度 $k_{\text{grip}}$ | 对数扫 3–4 个数量级 | 必须先按 §4.2 标定 |
| 次 1 | 工具 taxel 的**感觉延迟** $d$ | 0 → 200 ms | 与 body-schema 文献可比 |
| 次 2 | 工具通道**噪声** $\sigma$ | 0 → 3× 信号幅度 | |
| 次 3 | 某关节的**力矩权限** | 100% → 0% | 损伤轴,与 falsifier #2 共用 |

每条参数轴给出一条独立的滞回环。**至少两条轴上都出现,才算不是某个参数化的巧合。**

### 5.2 横轴的物理化(别偷懒)

不要用 solref/延迟毫秒当横轴。先算一个**物理耦合代理** $\rho(k)$ = 手部加速度与工具尖加速度的相关系数(或传递率),用它做横轴。这样"阈值"是关于物理耦合的,可跨实现比较。

### 5.3 基本量

- $k_\uparrow$:上扫时 $m^S_{\text{tool-tip}}$ 首次越过 0.5 的点
- $k_\downarrow$:下扫时越回 0.5 的点
- **滞回宽度** $\Delta=\log_{10}k_\uparrow-\log_{10}k_\downarrow$
- **环面积** $A=\oint m^S_{\text{tool}}\,d\log_{10}k$

### 5.4 ⭐ 扫速控制(**最关键的一步,不做则全部结论无效**)

**唯一最容易被骗的地方**:一阶弛豫滞后也会画出一个环,看起来像滞回,其实不是双稳。

判别方法:在**跨 4 个数量级的扫速**上重复:$T_{\text{sweep}}\in\{10,10^2,10^3,10^4\}$ s,拟合

$$A(r)=A_0+c\,r^{\beta},\qquad r=1/T_{\text{sweep}}$$

$$\boxed{\ \text{判据:}\ A_0>0\ \text{且 95\% CI 不含 0}\ \Rightarrow\ \text{真双稳滞回}\ }$$
$$A_0\approx 0\ \text{且}\ A\propto r\ \Rightarrow\ \textbf{只是弛豫滞后,不是滞回}$$

线性档 B 必须落在后者。若 B 也给出 $A_0>0$,说明你的测量或数值积分有 bug(线性一阶系统在数学上不可能有零扫速极限的环面积)。这是内建的**阴性对照**。

### 5.5 ⭐ 直接双稳判定(比画环更强,推荐作为主证据)

在 $k\in(k_\downarrow,k_\uparrow)$ 内**固定**一个值,分别从两条支路进入(从下方逼近 vs 从上方逼近),然后运行 $\ge 10^3$ s。

- **判据**:两条支路各自的"停留在初始支路"的比例在 30 个种子上都 $>0.9$ ⟹ 存在共存吸引子。
- 再加梯度化脉冲扰动,定位分界面(separatrix),报出**逃逸所需的最小扰动幅度**在两支上的不对称。
这比滞回环干净:它不依赖扫速,也不依赖阈值定义。

### 5.6 统计与样本量

- 设计:**30 种子 × 4 扫速 × 2 方向**(主参数轴);次参数轴各 12 种子 × 2 扫速。
- 检验:每种子内配对差 $\Delta_s=\log k_\uparrow-\log k_\downarrow$;单样本 Wilcoxon,要求中位数 $>0$,$p<0.01$。
- **噪声基线**:必须先跑「重复同方向上扫」估计阈值本身的重测标准差 $s_0$。要求 $\mathrm{median}(\Delta) > 3 s_0$。只有 $p$ 值不算数。
- **功效**:若真实 $\Delta\approx0.5$ 个数量级、$s_0\approx0.15$,则 $n{=}12$ 已有功效 >0.9,$n{=}30$ >0.99。**最小可接受 $n=12$,推荐 30。**

### 5.7 非对称的两个独立测量(memo 混淆了这两者)

1. **阈值非对称**:上面的 $\Delta$。这只说明有滞回,**不**说明"释放更慢"。
2. **时间常数非对称**:在阈值**之外**固定 $k$,做阶跃(突然给足/突然撤除耦合),拟合 $m^S(t)$ 的时间常数,得 $\tau_{\text{on}},\tau_{\text{off}}$。memo 的断言是 $\tau_{\text{off}}>\tau_{\text{on}}$。
   **预测(来自 §3.3)**:$\pi$ 常数化的消融应让 $\tau_{\text{off}}/\tau_{\text{on}}\to 1$。这是精度门机制的专属签名。

### 5.8 ⭐ 特异性对照(memo 没有,但少了它结论没意思)

对**一个与自我无关的划分变量**跑完全相同的协议:例如给「干扰球属于哪个物理簇」也配一个同款慢变+门控变量。

> 若它**同样**出现滞回 ⟹ 滞回只是"带门控的慢变量"的通用性质,**与自我边界无关**,整个叙事被抽空(即使 falsifier #1 通过)。

这条是防止"成功了但没意义"的护栏。

## §6 Baseline

| # | Baseline | 目的 | 预测 |
|---|---|---|---|
| **a1** | **固定 μ(正确划分)** | 学 μ 到底买到了什么 | 无工具/无损伤时应打平甚至更好;有工具/有损伤时应输 |
| **a2** | **固定 μ(故意错的划分)** | 闭包损失对划分是否真敏感 | 闭包误差显著更高;若没有,说明 §2 的损失对 μ 不敏感 = 规格失败 |
| **b** | **前馈 μ(argmax/后验)** | Φ-argmax / FEP-posterior 替身 | 无滞回;边界处 chatter;工具切换瞬态性能最差 |
| **c** | **线性 μ ODE** | 去非线性档 | $A_0=0$(§5.4 的阴性对照) |
| **d** | **BC/VLA 最小替身** | falsifier #4 的可跑版 | 见下 |
| **e** | **Dynamic Markov Blanket(2502.21217)复现** | 最近 prior art | *stretch goal*,只在前面几档都通过后才值得投入 |

**(d) 的具体构造**:因为主线无奖励,需要一个下游**探针任务**(工具尖到目标点)。
- 500 条脚本演示,小 transformer 策略,**动作空间固定填充**:含一个"工具"槽位,无工具时填 noop —— 刻意复刻 G0.5 那种手画 μ。
- 比较两条曲线:(i) 工具接上后达标所需 episode 数;(ii) 损伤后微调达标所需 episode 数。
- **诚实标注**:这个替身很小,**falsifier #4(bitter lesson)在这个预算下只能预注册,不能裁决**。任何"我们打赢了 VLA"的说法在这个规模上都是无效的。能说的只有:「在同等极小数据下,μ 路线的损伤恢复样本效率是 X 倍」。

**独立于下游任务的 μ 质量探针**(必报):划分与仿真真值的一致率;损伤后 μ 重收敛所需 episode 数;$\Delta_{\text{peek}}$(blanket 泄漏量)。

## §7 最先死的那步(按"最早能证伪整个方向"排序)

### D0 — 协议阳性对照(第 1–2 天,不含任何学习)
手装 H-A 双阱 + **手写的**驱动信号,零神经网络,跑 §5.4 全套扫速控制。
**若连把答案手装进去都测不出零扫速非零环面积 ⟹ 测量协议坏了。** 这是工具问题不是理论问题,但不先做,后面任何阴性结果都不可解释。

### D1 — ⭐ **第一周就该跑的那一个**:环增益 $G>1$ 在经验上够不够得着
不需要完整训练。做法:
1. 用**固定的正确 μ** 短训编码器/动力学(§4.4 阶段 1 即可,$5\times10^4$ 步);
2. **测量** self 通道与 world 通道之间的**精度对比** $\Delta\pi$,以及并入的净收益 $(g-c)$(即 §2.4 的 $g_i$ 减去 $\beta_B$ 类成本);
3. 代入 $G=\dfrac{\kappa\Delta\pi(g-c)}{4\gamma\tau_\pi}$,看在**不把 $\kappa$ 调到系统失稳**的前提下能否取到 $G>1$。

**这是最早、最便宜的杀点(2–3 天,大部分是分析)。**
**若实测 $\Delta\pi$ 很小** ⟹ 没有任何合法参数设置能让双稳涌现,只能靠手装立方项 ⟹ **wedge 当场塌掉**。

### D2 — 涌现滞回($a=0$,精度门开)
去掉手装双阱,跑全套 §5.4 + §5.5 + §5.8。这是 falsifier #1 的真实现。
**失败的含义(必须现在就说清,别到时候找补)**:
> 若 D2 阴性,诚实的退守是「滞回必须**架构性地装进去**」。那仍是一个可测的工程主张(装了 latch 的划分,是否在工具切换和损伤恢复上打赢无记忆划分?),但它**不再是** memo 的主张「μ 的双稳从自维持中涌现」。这是一个**道级 fork,归 Macheng 拍**:弱版本值不值得继续。

### D3 — 损伤重解(falsifier #2)
运动性 + 感觉性两种损伤,比 μ 重收敛速度 vs baseline (d) 的微调速度。

### D4 — 感官替代迁移(falsifier #3)
视觉训 μ → 换触觉阵列。成本明显更高,排在有正结果之后。

### D5 — Bitter lesson(falsifier #4)
**本预算内无法裁决**。只做预注册:写下"若 VLA 替身放大 10× 就追平,我们认输"的具体阈值,存档。

## §8 已知的、我认为最可能出问题的三处

1. **通道个体化**(§1.1):真实系统里"通道"不是给定的,而恰恰是要学的。phase 0 用特权 entity 列表回避了它。这是本规格最大的作弊点,**必须在任何对外表述里写明**。
2. **μ 的梯度驱动 $u_i$ 与 ODE 的混合**(§2.5):把梯度当"力"喂进动力系统,在理论上不是一个定义良好的物理量(它的尺度依赖损失的任意缩放)。缓解:对 $u_i$ 做 per-channel 的滑动归一化(RMS 归一),否则 $\kappa$ 的标定会随训练进程漂移,滞回阈值就跟着漂,污染 §5 的所有测量。**未验证设计选择,但我认为这是第一个会咬人的实现细节。**
3. **prior art 收窄**(§1.2):`2502.21217` 已占住"动态 Markov blanket 检测"。跑实验前**必须读正文**,确认它没有双稳/滞回。若它有,本线终止。这是唯一一件应该在写代码之前做完的事。

## ⓪ 预注册式预期（在跑之前写下，防事后找补）

rapid temporal recalibration 文献报告的前一试次效应**通常在适应侧**：前一试次的异步会把本试次的 PSS 朝该异步方向**移动**（"校准"），而不是"赖在原态不走"。

**因此本次预期：前一试次 SOA 的效应方向 = PSS 被拖向前一试次 SOA（再校准/适应侧），而不是迟滞侧。**

（本节在拿到任何结果之前写入，见 git 历史：commit `sync dry-run: 骨架 + 数据结构核实 + 分析/置换管线`。）

### 符号约定与它到本任务各统计量的映射（必须先钉死，否则符号会被随便解释）

Liaci/Kornmeier 2018 的约定是关于**知觉本身**的：
- **正 = 迟滞 / priming**（本试次的知觉朝前一试次的知觉方向）
- **负 = 适应**（朝反方向）

同步性判断（SJ）任务里，"前一试次"有**两个**可以拖动本试次的东西，必须分开：

| 统计量 | 含义 | 正号读作 | 负号读作 |
|---|---|---|---|
| `M2_presp` / `M3_prespK` | **前一试次的反应**对本试次反应的主效应 | **迟滞 / 选择重复**（说"同步"后更倾向再说"同步"）——这是 Kornmeier 约定的**直接**对应物 | 适应 / 交替 |
| `M2_soaXpsoa` / `M3_soaXpsoaK` | **soa × psoa 交互**：同步窗口（PSS）被前一试次 SOA 拖动的量 | PSS **朝**前一试次 SOA 移动 = **rapid temporal recalibration（文献称适应/再校准）** | PSS 朝反方向 |
| `dPSS_ms` | 同一件事的 model-free ms 版本：同步反应率曲线重心之差 PSS(psoa>0) − PSS(psoa<0) | 同上，正 = 再校准 | 同上 |
| `M1_psoa` | 任务书指定的主模型 `resp ~ soa + psoa` 里 psoa 的**主效应** | 前一试次 SOA 越正 → 本试次越倾向说"同步" | 反之 |

⚠️ **对 `M1_psoa` 的一条方法学诚实交代（在看结果之前就该说）**：SJ 的心理测量曲线是**峰形**（在 PSS 附近最高），不是单调的。因此"PSS 被拖动"这件事在数学上落在 **soa×psoa 交互**上，而**不是** psoa 的线性主效应上——把 logit P(sync) 近似成 `a − k(soa − c·psoa)²` 展开即得 `+2kc·(soa·psoa)`，psoa 的一次项只剩 `−kc²·psoa²`（偶函数，对称设计下线性 psoa 项期望≈0）。
所以：**任务书指定的 `resp ~ soa + psoa` 模型会系统性地看不见这个文献里最确凿的效应**。本报告按要求原样拟合并报告它（M1），同时报告能真正承载该效应的扩展模型（M2/M3）。两者都报，符号判定以 M2/M3 + dPSS 为准。

**"迟滞 vs 适应"在本数据里的最终裁定必须落在 `presp` 项上**，因为只有它是"知觉状态是否自我保持"的直接测量；`soa×psoa` 测的是"内部参考点是否被最近的刺激拖走"，那是另一个（且方向相反命名的）现象。

## ③ 置换方案说明（保持了什么 / 打破了什么）

置换的目的：给"跨被试平均的系数"造一个**零分布**，其中数据的所有非序列性质都被保留，只有序列结构被破坏。跑了**两个**零模型，因为它们保守程度不同。

统计量一律是**二级量**：先对每个被试单独拟合逻辑回归（手写 IRLS，`analyze_sync.py:irls`），再取跨被试均值。置换在**被试内**进行，因此零分布自动尊重被试异质性。

### Null A（主）—— 被试×session×block 内的整体试次重排

对每个 `id × session × block`（`4ukzx` 无 block，则为 `id × session`），把 **`(soa, resp[, sf])` 三元组作为一个不可拆的整体**随机重排试次顺序，然后**从重排后的顺序重新计算 lag-1/2/3**。

**保持（逐字不变）**：
- 每个 block 内 SOA 的**边缘分布**（9 档的计数一个都不变）⟹ 任何"每 block 平衡呈现"的设计约束被完整保留；
- 每个试次的 `(soa, resp)` **配对** ⟹ 每个被试的**心理测量函数完全不变**（`soa` 主效应、`soa²`、整体同步反应率、被试间差异全部逐字保留）；
- 试次总数、被试数、session/block 结构。

**打破**：
- 试次的**时间顺序** ⟹ 一切前序依赖：真实的序列效应，**以及 block 内的慢漂移**（疲劳、判据漂移、注意力波动）。

**这个 null 的理论弱点**：它连 block **内**的慢漂移也一起打破了，所以 block 内漂移造成的**伪**序列依赖原则上会被判成"显著"。所以有 Null B。
**实测修正（重要）**：Null A 实际上比这个悲观描述强 —— 因为重排是**在 block 内**做的，而 lag-1 配对 99.2% 落在同一 block 内，**block 之间**的反应率差异会原样保留在置换数据里并造出真实的正 lag-1 相关。实测 `presp` 的 Null A 零分布中心 = **+0.191**（不是 0），Null B = +0.158，两者同向。详见 ④.0 与 `diag_null_bias.py`。

### Null B（次，保漂移）—— 历史序列的循环平移

当前试次的 `(soa, resp)` 与它的时间位置**完全不动**；只把用作"历史"的序列在 `id × session` 内**循环平移 k 步**（k 从 `[10, n−10]` 均匀抽），再从平移后的序列取 lag-1/2/3，即 pseudo-psoa[t] = soa[(t+k) mod n]，pseudo-presp[t] = resp[(t+k) mod n]。

**保持**：
- `resp` 序列自身的**时间自相关与任何慢漂移**（因为 resp 的时间位置没动）；
- `soa` 序列自身的时序结构与边缘分布；
- `soa(t) → resp(t)` 的配对与心理测量函数；
- 被试内的一切。

**打破**：
- 历史与当前试次的**正确对齐**（错位 ≥10 试次）。

⟹ **Null B 比 Null A 保守**：慢漂移导致的伪依赖在 Null B 下**仍然存在于零分布里**，因此不会被误判为真效应。**代价**：如果真实效应有很长的时间尾（>10 试次），Null B 会把一部分真效应吸收进零分布，从而低估显著性（保守偏差）。

**两个 null 都显著 = 结论稳**；只有 Null A 显著 = 高度怀疑是慢漂移伪迹。零分布的均值（`null_mean`）本身就是漂移贡献的估计量，报告里一并给出。

### 置换 p 的计算

双侧，**以零分布均值为中心**：`p = (#{|null_i − mean(null)| ≥ |obs − mean(null)|} + 1) / (nperm + 1)`。
`nperm = 1000` ⟹ **p 的下限是 1/1001 ≈ 9.99e-4**，报告里出现 `9.99e-4` 一律读作"≤0.001，本次置换次数下不可再细分"。

**"以零分布均值为中心"这一步不是修饰，是结论级的**：多个统计量的零分布中心显著偏离 0（`presp` 偏 +0.19），直接对 0 做 t 检验会把符号读反。见 ④.0。

### ④.0 先说一件把结论翻过来的事：`presp` 的置换零分布**中心不在 0**

`hev9z` 上，`presp` 系数的零分布中心是 **+0.191（Null A）/ +0.158（Null B）**，而不是 0。
⟹ 跨被试 t 检验（对 0 检验，p_t = 0.474，"不显著"）**是错的参照系**；
⟹ 正确读数是 `obs − null_center = 0.048 − 0.191 = −0.143`，**显著为负**。

**为什么零分布中心是正的**（`diag_null_bias.py`，200 次置换，seed 20260728）：

| 模型 | obs_presp | nullA_mean | obs − null |
|---|---|---|---|
| `soa + soa² + presp` | 0.0513 | **0.1928** | −0.1415 |
| `soa + soa² + psoa + presp` | 0.0471 | **0.1911** | −0.1440 |
| `soa + presp`（去掉 soa²） | 0.0386 | **0.0629** | −0.0243 |
| `soa + soa² + psoa + soa:psoa + presp`（= M2） | 0.0483 | **0.1920** | −0.1437 |

诊断：偏倚不来自 `psoa` 项（加不加它零分布中心几乎不动），主要由**曲线形状项 `soa²` + block 级反应率异质性**共同产生 —— Null A 在 **block 内**重排，而 lag-1 配对 99.2% 落在同一 block 内，于是**block 之间的整体反应率差异会在置换数据里造出真实的正的 lag-1 相关**。这不是 bug：它意味着 Null A 实际上**已经把 block 尺度的慢漂移吸收进零分布**（比 ③ 里对它的悲观描述更强）。Null B（保漂移）给出同向、略小的中心（+0.158），两者一致。

**这一条是本任务最有价值的技术产出**：如果直接按"系数 > 0 且 t 检验显著 ⟹ 迟滞"来读，`hev9z` 的 `presp` 会被读成"接近 0、无效应"，`M3_presp2/3` 会被读成"显著的正迟滞"；接上正确的零模型之后，前者变成**显著为负**，后者的 lag-3 变成**不显著**。**没有置换零模型，这份数据的符号会被读反。**

### ④.3 一致 / 不一致清单

**一致的（两份数据集都成立）**：
1. **存在稳健的逐试次前序依赖**，两个零模型下 p_perm ≤ 0.001。
2. **刺激侧的 `soa × psoa` 交互显著为正**（hev9z +1.70，4ukzx +0.93），且 **lag-2 仍显著、lag-3 归零**。
3. **衰减尾很短**：1–2 试次。**没有任何一份数据显示多试次的 latch 式保持。**
4. **任务书指定的 `resp ~ soa + psoa` 主模型都不足以承载真正的效应**：hev9z 上它完全看不见（p_perm 0.51），4ukzx 上它显著但**把再校准和选择重复混在一起**（控住 `presp` 后就没了）。

**不一致的（这本身是重要信息）**：
1. **选择重复（`presp`）的符号相反**：hev9z **显著低于零模型（负 = 适应/交替）**，4ukzx **显著高于零模型（正 = 迟滞/priming）**，且量级差近一个数量级（−0.14 vs +0.43）。
2. **PSS 位移的方向相反**：hev9z **+16 ms 朝向**前一试次 SOA（再校准），4ukzx 的原始模型给 **−9.6 ms 背离**（但控住选择重复后就不显著了）。

**最可能的解释（未验证，属于假设不是结论）**：两份数据**不是同一个任务**（SJ vs TOJ，见 ④.2）。SJ 的反应"同步/不同步"与刺激的符号无关，因此选择重复与再校准可以分开；TOJ 的反应"谁先"与刺激符号**直接对应**，因此"重复上次的反应"与"PSS 朝反方向移动"在数学上是**同一件事的两种说法**——这正是 4ukzx 里控住 `presp` 之后 `psoa` 效应消失的原因。
⟹ **在符号对应的任务里，"迟滞"与"适应"这两个标签本身就不可分辨**，除非另有独立操纵。这是一条要带进自建实验设计的教训（见 ⑥）。

## ⑤ 降级声明（**这不是 embodiment 证据**）

**本报告测的是"视听同步性判断（simultaneity judgment）的前一试次依赖"。它不是身体所有权，也不是滞回的证据。任何把本报告写成"我们测到了 μ 的滞回"或"身体所有权有前序依赖"的表述都是偷换。**

具体的四条不可外推（沿用上游 memo §③，此处不重复论证）：

1. **DV 不是所有权。** 这里问的是"这两个事件同时吗"，不是"这是我的手吗"。所有权是因果推断的**结论变量**，同步性是它的**输入证据**之一。输入有滞回 ⇏ 结论有滞回；输入无滞回 ⇏ 结论无滞回。**两个方向都不成立。**
2. **模态不是视触。** 两份数据全是**视听**。视触同步判定的逐试次公开数据目前零命中。而 Chancel/Ehrsson 那一系的整个卖点恰恰是"身体情境**改变**视触同步判定"⟹ 模态与身体情境本身就是调制因子，不是可忽略的细节。
3. **不是率无关滞回。** SOA 是**随机**呈现的（这正是 rapid recalibration 范式的要求），没有单调扫描，没有扫速，环面积对扫速的外推无从做起。**强版本（率无关滞回）仍然只能自建实验。**
4. **`soa×psoa` 的"正号"不等于迟滞。** 见 ⓪ 的符号映射表：它是 PSS 被最近刺激拖走，文献命名为**再校准/适应**。把它写成"正号 = 迟滞"是最容易犯的偷换。

**本任务的正确定位**：这是**管线的 dry-run**。主要产出是 `analyze_sync.py` 这套（per-subject 拟合 → 二级检验 → 两个零模型的置换检验 → 多滞后）已验证可跑的代码，等所有权的逐试次数据到手直接复用。次要产出是一个真实数字（见 ①/④），它属于同步性判定，只属于同步性判定。

## ⑥ 管线复用说明：拿到所有权逐试次数据后要改哪几行

全部改动集中在 `analyze_sync.py`，共 **4 处**：

1. **`load()`（第 ~57 行起）** —— 加一个新分支，读所有权数据，把列名映射到管线的内部约定：
   `id`（被试）、`session`（连续的呈现序列单元）、`trial`（序内顺序）、`soa`（**被操纵的连续参数**：视触延迟 / 假手距离 / 化身相似度……）、`resp`（**二元所有权判定**，1 = "是我的"）、可选 `block`（置换单元）。
   若所有权是**连续评分**（7 点 Likert）而非二元：见第 4 点。

2. **`add_lags()` 的分组键（第 ~72 行 `groupby(["id","session"])`）** —— 改成新数据里"一段不间断呈现序列"的定义。**这一步必须核对**：lag 绝不能跨越一次错觉重新诱导（re-induction）或休息，否则 lag 就不是"前一试次"。

3. **`perm_A()` 的置换单元（第 ~150 行 `groupby(["id","session",blockcol])`）** —— 必须与真实的**呈现约束**同粒度。若新实验是**单调扫描**（method of limits，上行/下行），Null A 的"自由重排"就**不再合法**（它会破坏扫描本身）；那时正确的 null 是：**在扫描方向内保持顺序、只在上行/下行标签上重排**，或改用"把上行序列与下行序列整段交换"的置换。**这是搬管线时唯一真正需要重新想的地方**，代码里 `perm_A` 的 docstring 已写明它保持/打破了什么，照着重写即可。

4. **`subject_stats()` 的链接函数（第 ~93 行起）** —— 若 DV 是连续评分，把 `irls()` 换成最小二乘（`np.linalg.lstsq`），其余结构（M1/M2/M3 的设计矩阵、dPSS 的重心统计量）一字不改即可运行。

**不需要改的**：二级检验、两个零模型的 p 值计算、lag-1/2/3 的设计矩阵构造、`summarize_sync.py`、出图。

5. **（新增，来自本次实测）搬过去时必须先跑 `diag_null_bias.py` 这一步**——在新数据上确认 `presp`（或所有权判定的重复项）的**置换零分布中心在哪**。本次实测该中心是 **+0.19 而不是 0**，直接对 0 做检验会把符号读反。所有权数据大概率也有 block/session 级的整体倾向漂移（诱导强度、注意力、问卷判据），风险只会更大。

**搬过去时必须一起搬的三条纪律**：`M1`（任务书指定的线性模型）与 `M2/M3`（能承载峰形/交互效应的模型）**都要跑**。本次实测：hev9z 上 M1 完全看不见那个 p ≤ 0.001 的效应（M1 的 p_perm = 0.51），4ukzx 上 M1 显著但把两种机制混成一个数。⓪ 里那条数学论证是通用的。

**第三条纪律（来自 ④.3 的不一致）——设计自建实验时必须避开的陷阱**：如果被操纵参数的符号与二元反应的语义**直接对应**（像 TOJ 的"谁先"那样），那么"迟滞（重复上次的反应）"与"适应（判据朝反方向移动）"在数学上**不可分辨**。所有权判定 ("是我的手吗") 在这一点上更接近 SJ 而不是 TOJ（反应语义与延迟符号不对应），所以这个陷阱在所有权上**没那么危险**——但只要引入"哪只手更像我的"这种二选一措辞就会立刻掉进去。**因此所有权的逐试次 DV 应保持"是/否"而不是"A/B 二选一"。**

## ⑦ 已知局限（管线层面，非结论层面）

- **未排除作者标记的离群被试**（`4ukzx` 的 id 5、27）。理由见 ②。
- **`presp` 的解释受慢漂移污染**，这正是 Null B 存在的理由；两个 null 结论不一致时以 Null B 为准。
- **二级 t 检验假设被试层系数近似正态**；置换 p 不依赖这个假设，因此以置换 p 为准。
- IRLS 在极少数被试×模型组合上因完全分离（separation）返回 NaN，被 `nanmean` 跳过。**实测：hev9z 26/26 全部成功；4ukzx 的 M2/M3 为 31/32（1 名被试分离），M1 与 dPSS 为 32/32。**
- 置换次数 1000 ⟹ p 无法细分到 0.001 以下；多个核心统计量已经压在这个下限上。若要报更精确的 p，把 `nperm` 调到 10000（耗时线性放大，两个零模型合计约 100–110 分钟/数据集）。
- **未做多重比较校正**。本报告一共报了 17 个统计量 × 2 数据集 × 2 零模型。核心结论（`M2_soaXpsoa`、`dPSS_ms`、`M2_presp`）的 p 都压在置换下限 0.001 上，Bonferroni（×68）后仍 < 0.07，但严格说**边缘**；而像 `M3_psoa3`（p ≈ 0.006–0.009）这种就**过不了**校正，所以报告里已经标注"存疑不作结论"。
- **`presp` 的零分布偏倚机制只做到了经验定位（`soa²` 项 + block 级异质性），没有解析推导**。这不影响结论（置换 p 本身不依赖机制解释），但若要写成论文需要补。

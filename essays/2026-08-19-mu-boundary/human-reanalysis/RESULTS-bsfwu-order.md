**ANOVA**

| 效应 | F | df | p | η²p |
|---|---|---|---|---|
| Order (between) | 14.416 | (1, 183) | 1.99e-4 | **0.073** |
| Condition (within) | 90.551 | (1, 183) | 1.07e-17 | **0.331** |

Condition 主效应方向正常（Sync > Async，pooled 差 = +0.728，t(184) = +9.08，p = 1.7e-16，dz = +0.667）—— 期望范式下同步性操纵本身有效。

**关键简单效应（本裁决的依据）**

- **对比 A（决定符号的那个）— 同一个 Async 条件跨组比较：**
  - Syn1st（Async 排第二，此前已看过 Sync）：M = **−0.455**，95%CI[−0.719, −0.190]
  - Asyn1st（Async 排第一，无前置）：M = **+0.436**，95%CI[+0.215, +0.658]
  - 差（Syn1st − Asyn1st）= **−0.891**，95%CI[−1.232, −0.550]，t(183) = −5.156，**p = 6.7e-7**，Hedges d = **−0.756**，95%CI[−1.098, −0.457]（bootstrap，seed 20260728）
  - 判读：**先经历强条件 → 后续弱条件评分更低** ⟹ 按 Liaci 约定是**负号 = 适应/对比侧**。

- **对比 B — 同一个 Sync 条件跨组比较：**
  - Syn1st（Sync 排第一）：M = +0.625，95%CI[+0.401, +0.849]
  - Asyn1st（Sync 排第二，此前已看过 Async）：M = +0.845，95%CI[+0.628, +1.063]
  - 差（Syn1st − Asyn1st）= −0.220，95%CI[−0.531, +0.090]，t(183) = −1.402，**p = 0.163**（不显著），d = −0.206，95%CI[−0.513, +0.083]
  - 方向：**先经历弱条件 → 后续强条件评分更高**（+0.220）—— 这**同样是负号/适应侧**的方向，只是未达显著。

**符号判定（明确写出）**：**负号（适应/对比）**。主要依据 = **对比 A**（Async 在 Syn1st 组显著低于 Asyn1st 组，d = −0.76）。对比 B 方向一致但不显著，因此符号判定不依赖它。两个对比合起来是**同一个对比/锚定模式**：第二个条件被推离第一个条件，导致两条件差被放大。**没有任何一项支持正号（迟滞/priming）。**

| 效应 | F | df | p | η²p |

| Condition | 22.372 | (1, 183) | 4.48e-6 | 0.109 |

- Async 上的跨组差 = **−0.313**，95%CI[−0.616, −0.009]，t(183) = −2.033，**p = 0.0435**，d = −0.298，95%CI[−0.600, −0.010]
- Sync 上的跨组差 = −0.073，95%CI[−0.381, +0.236]，t(183) = −0.465，p = 0.643，d = −0.068

**结论：控制条目表现出方向完全相同、且统计显著的顺序效应。** 控制条目本应是不该被同步性驱动的安慰剂/需求特征条目，它们照样出现 Condition 主效应（p = 4.5e-6）和 Order×Condition 交互（p = 0.030）⟹ **顺序效应至少部分是需求特征/反应偏置，不是所有权特有的。判别力大幅下降，必须明说。**

**但不是完全没有特异性** —— 我额外跑了 Order × Scale(illusion vs control) on Async 的检验：
- Order × Scale 交互 **F(1,183) = 22.418，p = 4.38e-6，η²p = 0.109**
- 差分 (illusion_Async − control_Async)：Syn1st M = +0.436 vs Asyn1st M = +1.014；差 = **−0.578**，t(183) = −4.735，p = 4.4e-6，d = **−0.694**，95%CI[−1.014, −0.404]

⟹ 顺序效应在 illusion 条目上**显著大于**在 control 条目上（−0.891 vs −0.313，约 2.8 倍）。诚实读法：**存在一个真实的、非纯反应偏置的成分，但被一个同向的需求特征成分污染，无法用本数据把两者干净分离。**

## ⑤ 与 Zhang, Ma & Hommel 2015 (Front Psychol 6:1659, N=34) 对照

| | Zhang & Hommel 2015 | 本次 bsfwu Exp2 |
|---|---|---|
| 操纵路径 | **距离**（远→中 vs 近→中） | **同步性**（Sync 先 vs Async 先） |
| N | 34 | **185** |
| DV | 亲历的所有权评分 | **期望的**所有权评分（看视频） |
| 关键结果 | 远→中 (3.768) > 近→中 (3.056)，F(1,33) = 39.82，η²p = 0.547 | Async 在 Asyn1st (+0.436) > 在 Syn1st (−0.455)，F(1,183) = 19.17（交互），η²p = 0.095 |
| 符号 | **负（适应）** | **负（适应）** |

**裁决：一致，都是负号。** 两个完全独立的操纵维度（空间距离 / 时间同步性）、两个不同文化样本（中国 / 日本）、两种不同测量（亲历 / 期望）、N 相差 5.4 倍，**都落在适应/对比侧，都没有出现迟滞方向**。这是**对迟滞假设的收敛性反证**，比单独任何一条都强。

效应量上本次远小于 Zhang（η²p 0.095 vs 0.547）—— 但两者 η²p 不可直接比（不同设计、不同误差项、Zhang 的 N=34 会大幅高估 η²p）。方向的一致性才是可用信号。

## ⑥ 限制（不得省略）

1. **这是问卷式、block 级的顺序效应，不是逐试次滞回，更不是率无关滞回。** 每个被试对每个条件只给一次汇总评分（两个 block）。它最多支持/削弱「所有权有顺序依赖」这个**弱版本**；对「μ 边界有滞回（state→coupling 反馈、率无关、双稳）」这个强命题**既不能证实也不能证伪**。一个 2-block 设计在原理上无法区分滞回与单次对比锚定。

2. **本论文本身研究 expectancy / 需求特征（Lush 2020 那条线）** ⟹ 顺序效应可能由**期望**而非知觉动力学驱动，这个替代解释**无法用本数据排除**。而且本数据集比一般情况更严重：**被试从未接受过橡胶手程序，只看了视频**，DV 字面就是「你预期会体验到多少」。所以这里测到的顺序效应**几乎肯定至少部分是判断/锚定过程**，而非身体表征动力学。控制条目也显著（④）与此完全吻合。**严格讲，这个数据集不是「身体所有权的顺序效应」的直接证据，而是「关于身体所有权的期望的顺序效应」。用它去打迟滞假设时必须降权。**

3. **单一数据集，未预注册的二次分析。** 本分析的所有对比（尤其 ④ 的 Order × Scale 特异性检验）都是我事后指定的，未做多重比较校正；效应量 CI 为 bootstrap 百分位法，非精确非中心 F 区间。Exp1（N 更小，`Data_Tsuji_Imaizumi_Exp1.csv`，4846 bytes）未分析，因此无同数据集内部复制。

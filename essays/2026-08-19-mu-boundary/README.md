## 规格偏离清单

1. **任务 A 用 `float64` + RK4 定步长,不用 spec 未指定的积分器**。规格没写积分器;
   环面积在零扫速外推上对积分误差敏感,故显式选 RK4 并在测试里验证步长收敛。
2. **A(r) 拟合的 r 定义**:规格写 `r = 1/T_sweep`。照做。但规格给的扫速集
   `T∈{10,10²,10³,10⁴}` 是**为学习回路**设的(τ_x=2 s)。任务 A 无学习,故按
   **无量纲扫速** `r = τ_x/T_sweep` 扫 4 个数量级(τ_x=1),数值上等价于规格的意图
   (τ_obs ≪ τ_x ≪ T_sweep),但不必真跑 10⁴ 秒物理时间。
3. **A(r) 拟合改为对 β 做网格 + 线性最小二乘 profile**,而不是直接非线性三参数拟合。
   理由:三参数(A₀,c,β)在只有 4–6 个扫速点时非线性拟合极不稳定(β 与 c 强简并),
   profile 化后 A₀ 的 CI 才有意义。CI 用 bootstrap(over seeds),不用高斯近似。
4. **阴性对照按规格 §3.4 的正确写法**:`a=0, b=-γ<0, π≡const`(只置 a=0 会发散)。
   已在测试里断言"只置 a=0"确实发散,防止后人写错。
5. **任务 B 不做规格 §4.4 的完整两阶段训练**(2×10⁵ 梯度步)。D0 只问"存不存在非平凡
   划分",这是一个**关于数据的问题**,不需要 μ 的 ODE 参与。故用固定候选划分 +
   直接拟合 f / f⁺ 的方式来算 peek-gain。这是规格 §7 D0 的字面意图(D0 排在 D1 前,
   D1 才开始训编码器)。
6. **f / f⁺ 用「每通道滞后 + 平方项」特征上的岭回归,不用 MLP**。理由是**可算性**:
   划分搜索要评估上万个候选划分,而岭回归允许把全特征的 Gram 矩阵预先算好,
   任意划分退化成一次小 Cholesky(~30 ms/次)。MLP 会让搜索完全跑不动。
   f⁺ 的特征列是 f 的**严格超集**(全部 34 通道)⟹ 假设类严格更大,满足规格 §2.3 的要求。
7. **任务 B 的 z 用「self 通道的当前窗口」直接代替学出来的 z**(规格 §1.3 的编码器
   是 D1 以后的事)。D0 的 blanket 条件因此是在**原始通道空间**上判定的,
   这比在学出的 z 上判定更保守(更容易检出泄漏)——方向正确。
8. **`solref` 未做规格 §4.2 要求的力-位移标定**。任务 B 不扫握持刚度(那是 D2),
   只用 `eq_active` 的开/关两态来确认 rig 能工作。标定留给 D2。
9. **窗口长度 H**:规格 §1.3 用 H=8。任务 B 用 H=4(降维 / 样本效率)。

以下 6 条(#10–15)是 **v1 跑起来之后被实测逼出来的**偏离,#16–21 是 **v2 这轮**新增的
(每条在 `RESULTS-D0.md` 里有对应证据,代码里也各有一段注释):

10. **f⁺ 不再用更小的 λ**。规格 §2.3 要求给 f⁺ 更大容量以免欠拟合造成假阳性;实现成
    λ⁺=λ/10 后 f⁺ 反而过拟合、测试集更差,标定用的**故意泄漏**划分给出**负** Δ_peek
    (= 假装 blanket 成立)。改为逐预测器在 val 上选 λ。
11. **加了 val 划分 + 逐 target 选 λ**(规格只有 train/test 的概念)。不这么做,
    Δ_peek 测的是"正则化是否恰好匹配列数",不是信息。
12. **train/val/test 用分块交错(块长 200 控制步,2:1:1)而非连续切分**。
    OU babbling 非平稳,连续切分让 Δ_peek 出现 −0.46 的伪值。
13. **通道标准化后 winsorize 到 ±8σ**。接触尖峰的重尾会让 test MSE 被少数样本主导。
14. **peek-gain 的预测步长用 K=10(200 ms)而非 1 步**。K=1 时每条通道都能被自己的滞后
    外推,跨通道信息无增量 ⟹ 代理量结构性失效。
15. **可控性增益 g 的"不看动作"基线必须同时剔除 `frc1..3`**。MuJoCo motor 的
    `actuatorfrc` = gear·ctrl,与指令力矩通道逐字节相同;不剔除则 g 全体 ≈ 0。
16. **干扰球加了一条软系绳 + 重力补偿**(规格只说"伪随机风场")。纯 OU 风力下球会随机游走
    飘出工作空间(实测 z 冲到 +454 m),既不撞臂也就没有 world 签名。系绳与 agent 无关,
    球仍完全不可控。
17. **系绳加 y 方向分量 + 球移到臂实际占据的区域 + 半径 0.04→0.07**(v2)。v1 的球被拴在
    z=+0.10,而臂**举不起自己**(需要 4.05 N·m,执行器只有 ±3)所以垂在 z≈−0.36;
    且球是 freejoint、y 上无恢复力,接触会把它推出平面再也回不来(接触率随 rollout 长度
    从 3.8% 衰减到 0.56%)。修完接触率 0.54% → **27%**,且不再随时长衰减。
    y 系绳仍只作用在球上、与 agent 无关,**不构成绕过 blanket 的通路**。
18. **λ 网格上界从 1.0 加宽到 1e2**(v2)。f⁺ 有 273 列、f 只有 49 列,f⁺ 的最优 λ 常
    >1 被截断 ⟹ 欠正则 ⟹ 测试集更差 ⟹ Δ_peek 变负 ⟹ **伪造"blanket 条件成立"**。
    这是偏离 #10 的同一类病(f⁺ 的正则化不当造成假阳性)在网格边界上的复发。
19. **peek-gain 的预测步长 K 从 10 提到 20(400 ms)**(v2)。标定门的
    动态范围/std 之比 1.18 → 3.08,单这一项就是主要贡献。
20. **γ_c 不再用规格 §2.5 的默认值 1,改为逐 rollout 从数据标定**(v2):
    `γ_c = std(L_clo)/std(Σ_S gᵢ/N)`,两个 std 都在随机划分上量,实测 ≈ **20**。
    规格的 γ_c=1 在量纲上就是错的。
21. **新增一个规格里没有的诊断:反事实耦合探针**(v2)。`wind_seed` 与 `seed` 分流,
    同动作序列只换 world 噪声,量 self 侧通道的归一化 RMS 分歧。
    必要性见「已知问题」第一条 —— Δ_peek **量不了** rig 的耦合强度。

以下 6 条(#22–27)是 **D1/D2 这轮**新增的(证据见 `RESULTS-D1-D2.md`):

22. **Δπ 用「同通道反事实」而非规格字面的「self 通道 vs world 通道」组间对比**。
    规格 §7 D1 说"测量 self 与 world 通道之间的精度对比";照字面做给出 Δπ=0.233,
    而回路里真正起作用的量(同一条通道进/出边界时精度的变化)只有 **0.033**,
    差 7 倍。前者混进了"通道身份"(taxel 本来好预测、球本来不可预测)。
23. **D1 没做规格 §7 D1 第 1 步的短训编码器**(5×10⁴ 步)。沿用 D0 的岭回归代理量 ε,
    理由同偏离 #5/#6(可算性)。**代价是 Δπ 带特征类依赖**(见 #24 与已知问题),
    这是本轮最大的未闭合项。
24. **必须做特征类对照**(规格没有):笛卡尔坐标下 q1 的相对摆幅 0.98,
    换成信息等价的极坐标后塌到 0.007 —— 大摆幅主要是"线性+平方基解不出 atan2",
    不是信息缺口。任何用 ε 比值下的结论都要跨表示复核。
25. **规格 §3.3 的 H-B 字面形式 `κ·π(x)·(g−c)` 配零点居中的门,数学上不可能三稳**
    (F(0) 与 F'(0) 的符号要求互斥;κ 推到 1e4 仍不三稳,有回归测试)。
    改成**精度只门控收益**:`κ(π(x)·g − c)`。G 的表达式不变。
26. **D2 在 1-D 约化 ODE 上跑,不在 34 通道 rig 上**;参数(s = Δπ/π_max)取自 D1 实测。
    规格 §3.1 的 1-D 约化本身是"未验证设计选择",这条偏离把它继承下来了。
27. **§5.7 的 τ 同时在 `m^S` 与 `x` 两个观测量上报**。`m^S(x)=e^x/(e^x+e^{−|x|}+e^{−x})`
    在 x→−x 下不对称(x=0 处 =1/3),会在完全对称的动力学上量出 τ_off≠τ_on。

## 已知问题 / 诚实标注

- **D1 最重要的诚实标注**:相对精度摆幅 `s` 是**特征类相关**的量。同一份数据,
  笛卡尔表示给 s(q1)=0.98,极坐标表示给 0.007。报出的"表示不变读数 s ≲0.18"
  是取两种表示里都活下来的部分,**不是**一个理论无关的真值。要拿到理论无关的
  Δπ 必须在学出来的 z 上量(= 规格 §7 D1 的第 1 步,本轮未做)。
- **D2 的 A 档与 D 档逐位相同**不是复制粘贴事故:归一化后该 ODE 只依赖 (G, τ_π),
  两档这两个数相同。这正是特异性对照的**阴性结论**本身。
- **D2 的滞回是"能涌现"不是"会涌现"**:它需要工作点落进相对宽度 = s 的窗口
  (工具通道 1.3–2.6%),而目标函数自己的系数(γ_c=28.75、β_I=0.30)把每条通道
  放在窗口外 2–420 个窗口宽处。没有任何机制在做这个抵消。
- **规格 §5.1 要求"至少两条参数轴上都出现滞回"**;本轮只有一条(抽象外场 h)。
  握持刚度 `k_grip` 的力-位移标定(§4.2)仍未做 ⟹ 主参数轴还没扫过。

- 任务 A 的双稳是**手装的**(规格自己说了这是 positive control)。它**不**支持理论,
  只证明测量协议有效。任何"我们观察到滞回"的说法在这一步都是循环论证。
- 任务 B 的 peek-gain 是 CMI 的**下界**,欠拟合的 f⁺ 会造成 blanket 条件的假阳性
  (规格 §2.3 已警告),**过拟合的 f⁺ 同样会**(实测,见偏离 #10)。我们用
  "严格超集的特征列 + val 选 λ + 故意泄漏的标定划分"三件套来控这个偏差,但**不能排除**
  剩余假阳性。报出的"blanket 条件成立"只应读作"在本容量预算下未检出泄漏"。
- 任务 B 的通道集合是**特权 entity 列表**(规格 §1.1 方案 a),不是从像素学的。
  这是规格自认的最大作弊点,必须在任何对外表述里写明。
- 任务 B 的划分搜索是**贪心坐标下降 + 随机重启**,不是全局最优。报出的"非平凡划分存在"
  是存在性证据(找到即存在);"退化吸引域 87%" 依赖搜索算法,换算法会变。
- **⚠️ v1 的一条诊断已被 v2 证伪,写在最前面免得后人继承错误**:v1 说「标定门 ratio<1
  是因为接触率只有 0.54%」。**不对。** 把 v2 的协议(K=20 + 宽 λ 网格)用回 v1 那个坏 rig,
  ratio = **3.94**(v2 rig 是 3.64)——ratio 低是**协议**问题,不是 rig 问题。根因:
  `leaky_tool_self` 探的是**臂→工具**泄漏,这条泄漏根本不经过球,对接触率不敏感。
  **教训**:Δ_peek **不能**用来量 rig 的 world→self 耦合强度 —— taxel(blanket)会把
  球的影响完全屏蔽掉,那正是 blanket 在干活。要量耦合必须跳出估计器做反事实(偏离 #21)。
- **rig 的耦合缺陷本身是真的**,只是要用对的尺子:反事实分歧 D(6000) 从 v1 的 **0.045**
  提到 v2 的 **0.203**(4.5×)。接触率 0.54% → 27%。
- **v2 的接触率 27% 超出了题面给的 5–20% 目标带**。压回带内只能缩球(r=0.04 → 21.6%),
  但耦合强度会同时从 0.203 掉到 0.149。选了耦合更强的一档,理由是真判据是耦合与标定比值,
  不是那个中间代理。
- 规格 §2.5 的目标函数按**默认** γ_c=1 会塌到平凡解(v1:87% 随机初始化收敛到 |S|=1,
  且总是最安静的 taxel)。诊断:γ_c·g 项比 L_clo 项弱约 1.5 个数量级。修法是重标定而不是
  换搜索算法(v1 的约束搜索也停在下界)。v2 的标定值 ≈20,效果见 `RESULTS-D0.md` v2 节。
- 任务 A 的 A₀ 置信区间只反映**种子噪声**,不反映"只有 4–7 个扫速点、β 与 c 简并"的系统偏差。
  正确的判据是与线性对照给出的**分辨底 0.008** 比较,不是看 CI 宽度。

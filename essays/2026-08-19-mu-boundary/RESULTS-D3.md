## 0. 一句话裁决

**F1 触发,阴性。全量 30 seeds × 5 臂:S(self-seal 环开、动作耦合到现任 μ)与 C3(同一套 μ 动力学、动作耦合到一个与 μ 无关的固定通道集)在三条注册指标上全部不可区分(P1 ratio dz=−0.09 p=0.70;P2 Δret dz=−0.05 p=0.78;P3 rod_in dz=+0.14 p=0.51);S 与 S-noact(随机动作)亦全部不可区分(F3 触发:S 的任何特征都不是由其动作造成的);S 与 Omohundro 对照 C2 亦不可区分。** Smoke(6 seeds)曾在 P1 上给出一个 n=6 置换底上的分离(S 0.82 vs C3 1.06,p=0.032),30 seeds 后消失(S 1.17 vs C3 1.28)—— 按注册 falsifier,**不加参数救**。测到的是:在本 rig 的 μ 判据下,decoy(hand-shadow)被所有动态臂 100% 接纳且不挤出任何现任成员(P2 在注册容量成本下是空测试,见 §4/§6 exploratory);换体后 rod 在所有动态臂中都留在 μ 内(P3 无区分力);再接纳时间全由估计滞后主导。**「二阶 self-seal 环产生边界防卫」在此 rig 上死。**

## 1. 设计(闭环,D0–D2 没有的部分)

D0–D2 是开环(OU babbling → 离线 μ 估计 → 抽象一维慢变量)。D3 把它接成闭环(`mu_boundary/defense.py`):
- **epoch** = 500 控制步(10 s 仿真);每 epoch agent 选 1 个运动模式 mode ∈ 9(OU 幅度 {0.6,1.2,2.0} × 时间常数 {0.2,0.5,1.2} s);epoch 末在 6-epoch 滚动窗口(3000 样本,分块交错 2:1:1,块长 100,**K=20** 预测步长 = D0/D1 协议)上重估。
- **μ 观察器**(各臂**同一套**):每通道自我度 x_i;labels:x>θ→S,x<−θ→W,否则 B(θ=0.15)。
  `τẋ_i = −x_i + A·(π_i·g̃_i − c(|μ|))`,π_i = 1/(1+ε_i/ε₀),ε_i = ε_in(i∈μ)或 ε_out(i∉μ)—— D1 的同通道反事实;g̃_i = D0 可控性增益按非动作类通道 90 分位归一;c(|μ|)=c₀+c₁|μ|/N(容量成本,P2 的挤出机制)。
- **label-free 标定**(seed 0 随机模式基线,各臂共用):ε₀ = median(ε_own)=0.649;c₀ = median(π·g̃)=0.0238;A = 1/std(π·g̃)=5.61;c₁=0.15;τ=3 epoch。
- **五臂**(只在「动作被什么耦合」上不同):
  | 臂 | 动作 | μ 动力学 |
  |---|---|---|
  | **S** | ε-greedy bandit,reward = **上一 epoch 的 μ 成员**的平均 π(维护现任「我」—— 二阶,路径依赖) | 开 |
  | **S-noact** | 随机 mode | 开(F3 反事实) |
  | **C1** | 随机 mode | (π,g̃) 冻结在第一次测量值,x 弛豫(D2 gate_frozen) |
  | **C2** | bandit,reward = −球撞臂次数/100 + 一阶存续项(|q|<2.3) | 开(只作读出) |
  | **C3** | bandit,reward = **固定随机 12 通道集**的平均 π(与 μ 无关的门) | 开 |
- **日程**(epoch):基线 0–19;P1 三个 remove/return 周期 (20,30)(45,55)(70,80);P2 decoy 100–130;P3 rebody(rod 0.30→0.45 m,0.15→0.30 kg)130–156。
- **decoy** = hand-shadow:`d_t = 0.85 d_{t−1} + 0.15·hand_x + 0.01ξ`(环境生成,高 π,g̃>0);未激活时为白噪声。

**注册指标的操作化**(在 spec 基础上固定,未跑前写定):
- P1:每次装回后 rod 4 条 kp 通道 ≥3/4 进 μ 所需 epoch τ_k(cap 15);`ratio = mean(τ₂,τ₃)/τ₁`。
- P2:decoy 期(30 epoch)现任成员留存率 − 同长无扰基线期留存率(`Δret`);decoy 被接纳比例(epoch 110–130)。
- P3:rebody 后 12–26 epoch rod kp 在 μ 内比例;|S|>1 比例。
- 分离度:同种子配对 dz + 符号翻转置换 p(n=6 时 p 底 = 1/32 ≈ 0.031)。

## 3. P1 再接纳有记忆 — 读法
- 方向对(S 的 τ_late < τ₁),但 **C2 同量级**(0.80 vs 0.82)、S-noact 无(0.97)。C2 的 reward 与 μ 毫无关系 ⟹ 缩短来自「bandit 收敛后 mode 不再切换 ⟹ 窗口平稳 ⟹ 估计器更快把 rod 判进来」。这是 spec §4 预先写明的「只 P1 过 = 通用记忆,不构成防卫证据」情形,且 C2 把它进一步降到「通用的学习-收敛效应」。
- 离开时间 τ_leave 各臂 5–8 epoch 一致(= 窗口长度 6 的估计滞后)。

## 4. P2 抵抗改写 — 读法
- **没有任何一臂抵抗**:decoy 一激活全臂 100% 接纳(C1 冻结除外);现任成员留存与无扰基线无差(Δret 全在噪声底内);S vs C3 dz=−0.03。
- 结构原因(诚实):hand-shadow 在本 rig 的 μ 判据下是「可控 + 可预测」= 与 rod 同类,所以一阶判据**正当地**收它;而容量成本 c₁=0.15 使接纳一条通道只抬 c 0.004,**挤不出任何人** ⟹ 二阶「防卫」无对象。这是 P2 操作化的**协议有效性**问题(类比 D0-pos):在本注册参数下 P2 是空测试,不是 S 通过了 P2。→ §6 exploratory 检查 c₁ 加大到挤出真的发生时,S 是否留存更多。

## 6. Falsifier 裁决(全量 30 seeds)
- **F1(S≈C3 在 P1/P2/P3 上都不可区分 ⟹ 死)**:**触发**。三条注册指标 |dz|≤0.14,p≥0.51。Smoke 的 P1 弱分离在 30 seeds 下消失。不加参数救。
- **F2(需 fine-tune 才出现)**:未触发(没有出现过可救的信号)。
- **F3(冻结动作后恢复率不掉 ⟹ 非行动)**:**触发**。S vs S-noact 三条注册指标全无分离。
- 与 D2 的关系:D2 说「滞回是带门慢变量的通用性质」;D3 说「把动作耦合到 μ 上也不产生任何对 μ 改写的差异响应」。两步合起来:**在本 rig 的 μ 操作化(精度门控的可控性增益 + 容量成本)下,self-seal 既不产生自我特异的滞回,也不产生边界防卫。** 未测的是另一种 μ 操作化(见 §8)。

### 6b. Exploratory(非注册,明确标注;c₁ 0.15→1.5,其余不变,6 seeds,`results/d3_explore_c1.json`)
目的 = 协议有效性检查:注册容量成本下 decoy 挤不出任何人,P2 是空测试;把 c₁ 加大到「接纳一条通道抬 c ≈ 0.25·std(π·g̃)」,看挤出是否发生、发生时 S 是否留存更多。
结果(6 seeds,30 runs,130 s):c₁=1.5 把 μ 压到 |S|≈4(注册值下 12–13),rod 大部分时间在外(P3 rod_in 0.58–0.65,τ 接近 cap 15),无扰基线留存本身塌到 0.2–1.0 —— **regime 退化**。在这个退化 regime 里:decoy 接纳率降到 0.77–0.88(仍是全臂接纳);Δret:S +0.00±0.28,S-noact −0.22,C3 −0.22,C2 −0.11;S vs C3 dz=+0.54(p=0.29),S vs S-noact dz=+0.45(p=0.36)。**方向是「S 留存更多」,但 n=6、在噪声内、且 regime 退化到 μ 几乎不含身体** ⟹ 不构成证据,只是若有人要复活时唯一可起手的线索(先得找到一个既有挤出、μ 又不塌的 c₁ 窗口 —— 这正是 D1 的 fine-tuning 病,F2)。

## 8. Caps / Deviations(跑前写定的部分已在 §1;这里是跑中发现)
- D-1 C1 最初实现为「x 冻在 0」⟹ 全 B(一切在 μ 内,含球)退化;改为 D2 语义(π,g̃ 冻在第一次测量值,x 弛豫)后重跑 C1。smoke 表已是修正版。
- D-2 模式集原含姿态弹簧维度(供 C2 做 reach 任务),实测它造成窗口非平稳、估计器 test-MSE>1,**去掉**;C2 任务改为「少被球撞 + 存活集」。
- D-3 K=1 时所有平滑位置通道(含球)ε_own≈0 ⟹ μ 无意义;改回 D0/D1 协议 K=20。
- D-4 可控性增益按全通道 90 分位归一会被 a/frc 副本压扁 ⟹ 改按非动作类通道归一。
- Cap:epoch 级 μ 更新(10 s)+ 6-epoch 窗口 ⟹ 所有 τ 都被估计滞后 ~5–7 epoch 主导;P1 的可分辨动态范围只有 ~3 epoch。
- 未做:rebody 的 4R 变体(只做了 rod 长度/质量);Procrustes 等更强 μ 读出;E3 级的 prior-art 逐篇清(spec §7)—— 结果为阴性,不触发。

# Physical possibility: minimal mathematical witnesses

Run `python3 verify_structure.py` with Python 3.10+ (standard library only).

The script checks 6,144 finite-map recodings, Bell-state phase/marginal distinctions, ordinary classical pure-joint marginals, equal mean energy with different Hamiltonian evolution, and a real-quantum local-tomography counterexample. It writes `structure-witnesses.json` deterministically. These calculations illustrate stated mathematical claims; they are not empirical data, a cosmological simulation, or a full reconstruction of quantum theory.

Read the [research note](../../essays/2026-09-06-from-encoding-to-physical-possibility.md) for assumptions and interpretation. An independent model reviewer checked the main derivations, reproduced the initial witnesses, and independently verified the Hamiltonian example via matrix exponentiation. The rebit witness was independently derived in that review, then implemented here; this is not external peer review.
